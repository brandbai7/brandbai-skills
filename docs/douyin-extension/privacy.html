隐私政策

生效日期：2026年8月7日 · 适用版本：v0.3.3 及以后版本

本隐私政策适用于“BrandBAI 抖音下载助手”Chrome 扩展程序。本扩展由赵姜睿以 Chrome Web Store 个人开发者（Trader）身份发布和维护；对外品牌为布兰德老白 BrandBAI；产品运营、品牌、软件相关版权及商业授权主体为杭州岂飞品牌管理有限公司。赵姜睿系该公司法定代表人，并经公司授权进行本扩展的发布与维护。

一、我们处理哪些信息

当用户主动在抖音网页中使用插件时，插件会处理当前页面已经加载并可访问的信息，包括：

  • 当前抖音页面的网址、页面类型和搜索词；
  • 作品标题、作者、发布时间、公开互动数据、作品链接和素材地址；
  • 用户主动选择下载的公开视频、图文、封面、页面提供的原声和发布文案；
  • 当前页面可访问的公开一级评论、评论时间、公开互动信息及页面公开显示的 IP 归属地标签；
  • 用户的首次使用确认、悬浮按钮位置、下载任务状态和暂停继续进度。

评论者名称默认转换为稳定化名，原始昵称不写入评论导出表。

二、我们不处理哪些信息

插件不会要求用户向 BrandBAI 提交抖音账号密码，也不会读取、导出、保存或上传：

  • Cookie、请求头或浏览器登录凭据；
  • 验证码内容；
  • 抖音私信或非公开内容；
  • 抖音以外网站的浏览历史；
  • 设备精确定位；
  • 支付卡、银行账户、健康信息或信用资料。

插件会复用浏览器已经存在的抖音登录状态访问用户当前能够正常打开的页面，但开发者无法取得该登录凭据。

三、信息如何使用

上述信息仅用于用户明确发起的功能：

  • 识别当前页面和当前已加载作品；
  • 生成视频、图文、封面、原声或发布文案下载；
  • 生成作品清单、下载说明和一级评论 Excel；
  • 在本机生成结构化批量 ZIP；
  • 支持暂停、继续、本地去重、阶段成果导出和按钮位置记忆。

我们不会使用这些信息投放个性化广告、进行信用评估、建立跨网站用户画像或出售给第三方。

四、本地保存与传输

核心说明：页面识别缓存、下载任务状态、用户确认状态和评论结果保存在用户本机。批量 ZIP、Excel 和其他文件在本机生成，不上传至 BrandBAI 控制的服务器。

插件仅与抖音网页及页面提供的抖音素材域名通信，以完成用户当前页面识别和用户主动选择的下载。相关平台处理行为同时受抖音自身规则与隐私政策约束。

五、数据保留与删除

  • 关闭相关标签页时，插件会清理部分页面识别缓存；
  • 用户可以在插件中删除本次评论下载记录；
  • 卸载插件会清除 Chrome 为该扩展保存的本地数据；
  • 已下载到电脑中的 ZIP、Excel、视频、图片、音频或文本文件不会随插件记录自动删除，需要用户自行管理和删除。

六、权限与最小访问范围

插件仅请求完成现有功能所需的下载、本地存储、侧边栏、本机 ZIP 整理权限，以及抖音网页和抖音素材域名访问权限。插件不会在抖音以外的网站运行内容脚本，也不会为未来功能预留额外权限。

七、用户责任

用户应仅下载和使用本人拥有权利、已获得合法授权或法律允许使用的内容，不得使用插件绕过登录、验证码、访问控制、签名、付费限制或平台技术措施。用户对下载、保存、分析、传播和商业使用相关内容的合法性承担责任。

八、未成年人

本插件面向具备相应民事行为能力并能够判断内容使用权利的用户。未成年人应在监护人指导下使用。

九、政策更新

如插件的数据处理方式发生实质变化，我们会在扩展界面、商店页面或本政策中进行明显说明，并在需要时重新取得用户确认。
