隐私政策

生效日期：2026年8月12日 · 适用版本：v0.10.8 及以后版本

本隐私政策适用于“BrandBAI 下载助手”Chrome 扩展程序。本扩展由赵姜睿以 Chrome Web Store 个人开发者（Trader）身份发布和维护；对外品牌为布兰德老白 BrandBAI；产品运营、品牌、软件相关版权及商业授权主体为杭州岂飞品牌管理有限公司。赵姜睿系该公司法定代表人，并经公司授权进行本扩展的发布与维护。

一、适用平台与单一用途

本扩展帮助用户在其当前已登录且有权访问的抖音、TikTok、小红书及天猫/淘宝页面中，识别页面已经展示的公开内容，并按用户主动选择在本机完成下载、结构化整理、可选本机翻译和导出。

本扩展不自动生成账号结论、达人合作判断、商品匹配、投放建议或商业效果承诺。

二、我们处理哪些信息

用户确认本版本的明显披露后，扩展在打开受支持页面时会自动识别当前平台、页面类型和当前已经展示的内容，用于填充页面入口与侧栏。只有用户点击相应按钮后，扩展才会下载、导出或进行可选的 TikTok 本机双语处理。用户未确认或撤回确认时，扩展不会继续识别、缓存、下载、导出或翻译页面内容：

  • 抖音：当前页面网址、页面类型、搜索词和来源链接；作品标题、作者、发布时间、公开互动数据、作品链接和素材地址；用户主动选择的视频、图文、封面、页面提供的原声、发布文案及当前页面可访问的公开一级评论和公开 IP 归属地标签。
  • TikTok：当前页面网址、页面类型、搜索词、搜索标签、当前可见位次和来源链接；作品发布文案、作者、发布时间、公开互动数据、作品链接和素材地址；用户主动选择的视频、图集、封面、页面可用原声和公开一级评论。
  • TikTok 本机双语：用户主动启用时，需要翻译的作品文案或已采集一级评论原文，以及语言识别结果、译文、翻译状态和生成时间。
  • 小红书：当前页面网址、页面类型、搜索词和来源链接；公开笔记标题、正文、话题、作者、发布时间、互动数据、素材地址、公开 IP 属地和公开一级评论；跨关键词采集时的关键词、当前选择、来源页面、笔记标识和作者汇总。
  • 天猫/淘宝：当前商品页面网址、商品 ID、页面类型和采集时间；商品标题、品牌、店铺、参数、可见规格、价格与权益、服务承诺、主图、图文详情图片和页面提供的视频；用户主动打开相应完整界面后可访问的公开评价和问大家内容。
  • 本机任务状态：首次使用及新版披露确认状态、页面入口位置、当前选择、任务进度、暂停继续检查点、完成状态，以及用户主动启用 TikTok 双语时产生的本机翻译缓存。

普通评论者、评价者和回答者名称在导出中默认转换为稳定化名。作品作者、笔记作者、商品主体和来源链接仍可能包含页面公开身份信息。

三、我们不处理哪些信息

插件不会要求用户向 BrandBAI 提交平台账号密码，也不会读取、导出、保存或上传：

  • Cookie、请求头或浏览器登录凭据；
  • 验证码或恢复码；
  • 私信、订单、支付信息或其他非公开内容；
  • 受支持平台以外网站的浏览历史；
  • 设备 GPS 或精确定位；
  • 支付卡、银行账户、健康信息或信用资料。

插件会复用浏览器已经存在的平台登录状态，处理用户当前能够正常打开的页面，但开发者无法取得这些登录凭据。

四、信息如何使用

上述信息仅用于本扩展的单一用途：

  • 在用户确认本版本明显披露后，自动识别当前平台、页面类型和当前已加载内容，以填充页面入口与侧栏；
  • 生成用户主动选择的视频、图片、封面、音频、文本和商品资料下载；
  • 生成作品、笔记、评论、商品、评价或问答 Excel；
  • 在本机生成结构化 ZIP 与下载说明；
  • 支持本机去重、暂停继续、阶段成果导出和入口位置记忆；
  • 在用户主动选择时，生成 TikTok 文案或一级评论的中英双语导出。

我们不会把这些信息用于个性化广告、信用评估、跨网站用户画像或出售给第三方，也不会用于与上述单一用途无关的目的。

五、TikTok 本机语言识别与翻译

TikTok 双语功能调用兼容 Chrome 桌面版提供的内置语言识别与本机翻译 API：

  • 原文始终保留，译文用于跨语言检索和初步理解，不替代原文证据；
  • 文本不会发送到 BrandBAI 或第三方翻译服务器；
  • 首次使用某个语言对时，Chrome 可能下载相应本机模型，该过程由 Chrome 管理；
  • 若浏览器不支持、语言不确定、语言对不可用或翻译失败，扩展不会自动调用云端服务，而是保留原文并写明状态。

用户撤回本版本确认后，扩展会停止并释放正在使用或等待中的本机语言识别器和翻译器。Chrome 为本机语言能力下载和管理的本机语言模型不属于扩展任务文件，扩展不会自动删除；用户可通过 Chrome 提供的设置自行管理。

六、本地保存与网络通信

核心说明：页面识别缓存、任务状态、用户确认状态和翻译缓存在用户本机保存。ZIP、Excel、视频、图片、音频和文本文件在本机生成，不上传到 BrandBAI 控制的服务器。

扩展只与受支持的抖音、TikTok、小红书和天猫/淘宝页面，以及这些页面直接提供的必要媒体资源域通信，以完成用户确认后的当前页面识别，以及用户主动选择的下载、导出和本机翻译。当前安装清单列明 20 条受支持页面及必要媒体域访问规则，包括天猫/淘宝商品视频下载可能使用的阿里临时签名视频域；扩展未申请全部网站访问权限。

BrandBAI 不接收页面内容、任务状态、翻译缓存或下载结果，也不会出售这些数据或主动共享给其他数据接收方。为执行用户选择而向相应平台页面或其必要媒体资源发出的请求，仍由相应第三方平台按其自身规则处理。

各平台页面和媒体由相应第三方平台提供，相关访问与内容处理同时受其自身规则和隐私政策约束。

七、数据保留与删除

  • 页面识别缓存和临时任务状态只为当前操作、恢复和去重使用；
  • 用户可在扩展侧栏底部点击“数据与授权”，取消勾选本版本确认。撤回后扩展会停止新的页面处理，取消进行中的受控下载或 ZIP 整理任务，清理仍由扩展控制的未完成临时文件与相应任务状态，并释放正在使用或等待中的 TikTok 本机语言识别和翻译资源；
  • 用户可以通过扩展提供的任务删除能力清理相应记录（如该页面提供该入口）；
  • 用户可在 Chrome 中清除此扩展的网站数据或卸载扩展，以清除 Chrome 为扩展保存的本地状态与翻译缓存；
  • 已经完成并保存到下载目录的 ZIP、Excel、视频、图片、音频或文本文件不会随插件记录自动删除，需要用户自行管理和删除；已交由 Chrome 写入下载目录的文件或下载记录也由 Chrome 和用户管理。
  • Chrome 为本机语言能力下载和管理的本机语言模型不会在用户撤回确认或卸载扩展时由扩展自动删除。

八、权限与最小访问范围

扩展请求 5 项扩展权限：下载、本地存储、侧边栏、离屏本机 ZIP 整理和受控脚本注入；并使用安装清单列明的 20 条四平台页面及必要媒体域访问规则。受控脚本注入只在用户确认当前版本明显披露后，把安装包内自带的页面桥接脚本注入当前受支持标签页；撤回确认时停用桥接并恢复被观察的页面网络接口。扩展不下载或执行远程代码，未申请全部网站访问权限，不会在无关网站运行内容脚本，也不会为尚未提供的功能预留无关权限。

相较 v0.10.1 的 19 条访问规则，v0.10.8 新增 1 条阿里临时签名商品视频 CDN 规则（*.cloudvideocdn.taobao.com），仅用于用户主动下载天猫／淘宝商品页直接提供的视频素材；未新增支持平台、数据用途、共享对象或 5 项扩展权限。

九、明显披露与政策更新

v0.10.1 将适用范围由三平台扩展为抖音、TikTok、小红书和天猫/淘宝四个平台，并增加 TikTok 本机翻译及必要媒体域披露。v0.10.8 保持相同单一用途、共享对象、支持平台和扩展权限；除补充本机任务启动、完成状态、撤回清理及 Chrome 管理资源的边界外，还新增上述 1 条阿里临时签名商品视频 CDN 规则，用于用户主动下载天猫商品视频。

扩展在开始处理页面内容前检查用户是否已有当前有效的明显披露确认；没有有效确认时会先展示说明并请求确认。用户不确认或撤回确认时，不会继续识别、缓存、下载、整理或翻译页面内容。

如未来的数据处理方式、平台范围、用途、共享对象或存储方式发生实质变化，我们会先更新扩展内明显披露、Chrome Web Store 数据披露和本政策，并在需要时重新取得用户确认。

English summary

After the user accepts the current in-product disclosure, BrandBAI Download Assistant automatically identifies the supported Douyin, TikTok, Xiaohongshu or Tmall/Taobao page and content currently shown to populate its interface. Downloads, exports and optional TikTok on-device translation occur only after a user action. Withdrawing consent stops further processing and controlled jobs, removes extension-controlled unfinished temporary files and task state, and releases active or pending on-device translation resources. Completed downloads and Chrome-managed language models are not automatically deleted. Version 0.10.8 adds one Alibaba temporary signed product-video CDN rule solely for user-initiated Tmall/Taobao video downloads; it adds no supported platform, data purpose, data recipient or extension permission. The extension does not read or upload passwords, cookies, request headers or verification codes. Contact: brandlaobai@163.com.
