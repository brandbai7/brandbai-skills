隐私政策

更新日期：2026年9月15日 · 适用名称：电商采集大师 · BrandBAI

本政策适用于原“BrandBAI 采集大师／BrandBAI 下载助手”更名后的同一 Chrome 扩展。v0.11.160 相比 v0.11.158 仅更新品牌显示，不新增扩展权限、网站访问范围、采集用途或共享对象。

本扩展由赵姜睿以 Chrome Web Store 个人开发者（Trader）身份发布和维护；对外品牌为布兰德老白 BrandBAI；产品运营、品牌、软件相关版权及商业授权主体为杭州岂飞品牌管理有限公司。赵姜睿系该公司法定代表人，并经公司授权发布与维护本扩展。

一、单一用途和用户操作

在用户当前已登录且有权访问的抖音、TikTok、小红书、微博和天猫／淘宝页面中，识别公开内容，按用户选择在本机下载、结构化整理和导出。有效确认《使用与数据说明》后，扩展会识别当前受支持页面以填充界面；下载、导出、受控加载及可选 TikTok 本机翻译由用户主动发起。未确认或撤回确认时，停止受控页面处理。

扩展不自动生成账号结论、达人合作判断、商品匹配、投放建议或商业效果承诺，不替用户发文、互动、下单或支付。

二、处理的信息

  • 当前页面与来源：受支持页面地址、页面类型、公开内容标识、搜索词、已加载列表及来源链接；不追踪无关网站的浏览历史。
  • 内容素材：公开标题、正文、话题、作者、发布时间、互动数字、图片、视频、封面、可用音频及其媒体地址。
  • 评论和评价：当前页面实际提供的公开内容、时间、互动数字、公开地区／IP 属地标签、必要来源与对象标识。普通评论者、评价者、回答者名称在导出中默认转换为稳定化名；作品作者及来源仍可能包含公开身份信息，化名不等于完全匿名。
  • 商品资料：商品标识、标题、店铺、主图、详情、视频、参数、可见规格、价格与权益、库存／销量／服务等页面公开信息的采集时快照；商品评价与问大家按用户选择独立保存。
  • 小红书：仅处理用户手动浏览后当前已加载的公开笔记、卡片与手动展开加载的评论，不自动翻页、遍历笔记或模拟账号运营。
  • 本机任务信息：确认状态、界面入口位置、当前选择、任务记录、去重信息、暂停继续检查点、完成／部分结果状态。
  • 可选本机双语：TikTok 原文、语言识别结果、译文、翻译状态与本机缓存，仅在用户主动启用时处理。

三、不以哪些信息为采集对象

扩展不要求向 BrandBAI 提交平台密码，不提取或导出 Cookie、请求头、登录凭据、验证码、恢复码；不采集私信、订单、支付记录、收货地址或其他非公开内容，不读取设备 GPS，不建立个人健康或信用档案。

页面公开内容可能自行包含敏感信息，用户应按实际用途核查并作必要的删减或脱敏。复用浏览器已有登录状态不等于向开发者提供登录凭据。

四、处理目的与存储

信息仅用于用户所选的本机资料包、媒体文件、文本、Excel 及可恢复的任务进度。页面识别缓存、任务状态、用户确认和可选翻译缓存保存在本机；下载结果保存在用户本机下载目录，不上传至 BrandBAI 控制的服务器。

我们不出售这些数据，不用于个性化广告、跨网站画像、信用评估或放贷，也不用于与扩展单一用途无关的目的。

五、网络与第三方平台

扩展与安装清单列明的受支持页面及其必要媒体资源域通信，用于已确认后的识别和用户发起的下载。并非离线浏览器，也不承诺平台看不到请求；平台仍可按自身规则处理访问与媒体请求。扩展未申请全部网站访问权限。

TikTok 双语使用兼容 Chrome 桌面版提供的本机语言识别和翻译能力。首次启用某语言对时 Chrome 可能下载模型；待译文本不发送到 BrandBAI 或云端翻译服务。不支持或失败时保留原文和状态，不自动回退到云服务。原文优先，译文不保证完全准确。

六、权限

  • downloads：保存用户主动选择的文件并跟踪下载结果。
  • storage：保存本机确认、设置、选择、任务状态与可选翻译缓存。
  • sidePanel：显示识别、下载、进度与用户控制界面。
  • offscreen：使用安装包内离屏页面完成本机 ZIP 整理、音频与文件准备。
  • scripting：在有效确认后注入安装包内自带的受控桥接脚本，识别当前受支持页面提供的公开数据。

精确网站规则以提交的 manifest.json 为准，v0.11.160 与 v0.11.158 相同。所有扩展执行代码随安装包提交；不下载或执行远程 JavaScript／WebAssembly。媒体下载是内容保存，不是远程扩展代码。

七、保留、撤回与删除

  • 可在侧栏“数据与授权”撤回确认，停止后续页面处理和受控任务，清理扩展仍控制的未完成临时文件及相关任务状态，并释放活动或等待中的本机语言资源。
  • 支持的任务可单独删除记录；记录删除与本机已下载文件删除是两件事。
  • 卸载或清除扩展存储可清理相应本机状态，但用户应自行备份需要保留的结果。
  • 已保存的 ZIP、Excel、媒体、文本文件和 Chrome 管理的下载记录不会随扩展任务删除而自动清除，须由用户自行管理。
  • Chrome 下载管理的语言模型不属于扩展任务文件，扩展不会自动删除。

八、边界、更新与联系

只处理有权访问的公开内容，不绕过登录、验证、访问控制、付费限制或平台技术措施。遇到验证、风控、账号限制应停止使用并按平台官方流程处理；扩展不保证不会触发限制。用户须遵守平台规则、内容权利和适用法律；未成年人应在监护人指导下使用。

若未来用途、数据处理、网站范围、共享对象或存储方式实质变化，将同步更新扩展内披露、商店信息及本政策，并在需要时重新请求确认。

English summary

Ecommerce Collector · BrandBAI identifies public content in supported Douyin, TikTok, Xiaohongshu, Weibo and Tmall/Taobao pages after valid in-product consent. Downloads, controlled loading, exports and optional TikTok on-device translation require a user action. Xiaohongshu processing is limited to manually browsed and already-loaded content. Public content, sources, task state and downloaded files remain on the user's device and are not uploaded to developer-controlled servers. Requests still reach the relevant platforms or media hosts. The extension does not extract or export passwords, cookies, request headers or verification codes. Completed downloads and Chrome-managed language models are not automatically removed when task records are deleted or consent is withdrawn. Version 0.11.160 changes branding only relative to 0.11.158 and adds no permissions, hosts, purposes or recipients. Contact: brandlaobai@163.com.
