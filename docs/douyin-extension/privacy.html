隐私政策

更新日期：2026年8月10日 · 适用版本：v0.7.2 及以后版本

本隐私政策适用于“BrandBAI 下载助手”Chrome 扩展程序。本扩展由赵姜睿以 Chrome Web Store 个人开发者（Trader）身份发布和维护；对外品牌为布兰德老白 BrandBAI；产品运营、品牌、软件相关版权及商业授权主体为杭州岂飞品牌管理有限公司。赵姜睿系该公司法定代表人，并经公司授权进行本扩展的发布与维护。

一、我们处理哪些信息

当用户主动在抖音、小红书或天猫/淘宝网页中使用插件时，插件会处理当前页面已经展示并可访问的信息，包括：

  • 当前受支持平台页面的网址、页面类型、搜索词和用户主动选择的条目；
  • 抖音作品的标题、作者、发布时间、公开互动数据、作品链接、视频或图文、封面、页面提供的原声、发布文案与公开一级评论；
  • 小红书笔记的标题、正文、话题、作者、发布时间、公开互动数据、图片、页面可保存的视频、公开一级评论，以及主页或搜索结果中的当前可见列表信息；
  • 天猫/淘宝商品的标题、店铺、可见规格、参数、价格/销量/库存快照、促销与服务信息、主图、详情图、页面提供的视频、公开评价、追评及问大家内容；
  • 页面公开显示的时间、地区或 IP 归属地标签，以及评论、评价或问答的公开互动信息；
  • 用户的首次使用确认、悬浮按钮位置、下载任务状态和暂停继续进度。

结构化导出会按相应功能对普通评论者或评价者名称进行稳定化名处理；平台公开内容仍可能包含用户主动选择保存的正文或素材。

二、我们不处理哪些信息

插件不会要求用户向 BrandBAI 提交平台账号密码，也不会读取、导出、保存或上传：

  • Cookie、请求头或浏览器登录凭据；
  • 验证码内容；
  • 平台私信、订单详情或其他非公开内容；
  • 受支持页面以外的网站浏览历史；
  • 设备精确定位；
  • 支付卡、银行账户、健康信息或信用资料。

插件会复用浏览器已经存在的平台登录状态访问用户当前能够正常打开的页面，但开发者无法取得该登录凭据。

三、信息如何使用

上述信息仅用于用户明确发起的功能：

  • 识别当前受支持的平台、页面类型和当前已加载条目；
  • 生成用户主动选择的视频、图片、封面、页面提供的原声、发布文案或商品素材下载；
  • 生成作品、笔记、商品、评论、评价、问答清单及完成状态说明；
  • 在本机生成结构化批量 ZIP；
  • 支持暂停、继续、本地去重、阶段成果导出和按钮位置记忆。

我们不会使用这些信息投放个性化广告、进行信用评估、建立跨网站用户画像或出售给第三方。

四、本地保存与传输

核心说明：页面识别缓存、下载任务状态、用户确认状态和评论结果保存在用户本机。批量 ZIP、Excel 和其他文件在本机生成，不上传至 BrandBAI 控制的服务器。

插件仅与抖音、小红书、天猫/淘宝网页及这些页面提供的必要素材域名通信，以完成当前页面识别和用户主动选择的下载。相关处理行为同时受各平台自身规则与隐私政策约束。

五、数据保留与删除

  • 关闭相关标签页时，插件会清理部分页面识别缓存；
  • 用户可以在插件中删除本次评论下载记录；
  • 卸载插件会清除 Chrome 为该扩展保存的本地数据；
  • 已下载到电脑中的 ZIP、Excel、视频、图片、音频或文本文件不会随插件记录自动删除，需要用户自行管理和删除。

六、权限与最小访问范围

插件仅请求完成现有功能所需的下载、本地存储、侧边栏、本机 ZIP 整理权限，以及抖音、小红书、天猫/淘宝网页和各自必要素材域名的访问权限。插件不会在其他网站运行内容脚本，也不会为未来功能预留额外权限。

七、用户责任

用户应仅下载和使用本人拥有权利、已获得合法授权或法律允许使用的内容，不得使用插件绕过登录、验证码、访问控制、签名、付费限制或平台技术措施。用户对下载、保存、分析、传播和商业使用相关内容的合法性承担责任。

八、未成年人

本插件面向具备相应民事行为能力并能够判断内容使用权利的用户。未成年人应在监护人指导下使用。

九、政策更新

如插件的数据处理方式发生实质变化，我们会在扩展界面、商店页面或本政策中进行明显说明，并在需要时重新取得用户确认。
