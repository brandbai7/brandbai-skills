v0.10.8 本机任务与撤回边界

  • 可靠启动：本机 ZIP 整理会等待本机整理模块明确就绪并确认任务；未完成确认时不会把任务显示为已经启动，而会给出实际错误。
  • 如实完成：即使 Chrome 的扩展后台进程重启，扩展仍会恢复本机任务回执和最终状态，并区分完整完成、部分完成、页面未提供、质量排除与下载失败。质量排除不会抵扣或掩盖真实下载失败。
  • 避免重复：同一标签页同一时间只启动一个受控 ZIP 任务，同一任务的重复请求会被拒绝，避免重复下载或相互清理文件。
  • 撤回与清理：撤回确认后停止新的页面处理和受控任务，清理仍由扩展控制的未完成临时文件与任务状态，并释放正在使用或等待中的 TikTok 本机翻译资源。已经完成并保存到下载目录的文件，以及由 Chrome 管理的本机语言模型，不会被扩展自动删除。

v0.10.8 未新增支持平台、数据用途、共享对象或扩展权限；为兼容用户主动下载的天猫商品视频，安装清单新增 1 条阿里临时签名视频 CDN 访问规则，不用于读取新的数据类别或执行远程代码。

重要的数据处理说明

插件处理的网站内容包括：用户确认本版本数据说明后，自动识别当前抖音、TikTok、小红书及天猫/淘宝页面已经展示并可访问的公开作品、笔记、商品、素材地址、互动数据、一级评论、评价和问答，以填充页面入口和侧栏；下载、导出及本机双语只在用户点击后执行。

页面内容、任务数据、翻译缓存和下载结果不会上传到 BrandBAI 控制的服务器。TikTok 双语功能调用兼容 Chrome 桌面版的内置语言识别与本机翻译能力；首次使用某个语言对时，Chrome 可能下载本机模型。浏览器不支持或翻译失败时，插件保留原文并明确记录状态，不自动调用云端翻译。

插件只在受支持的平台页面运行，并访问这些页面直接提供的必要媒体域完成用户主动选择的下载；不会建立跨网站浏览画像，不出售数据，也不用于广告或信用评估。平台页面与媒体由相应第三方平台提供，并同时受其自身规则和隐私政策约束。

插件只处理当前账号能够正常访问的内容，不绕过登录、验证码、访问控制、签名、付费限制或平台技术措施。“当前已加载”“当前可见已到底”和“平台全部内容”是不同状态；未展示、未加载、折叠或不可访问的内容保持未知或未提供，不推测补全。
