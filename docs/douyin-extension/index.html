重要的数据处理说明

插件处理的网站内容包括：当前抖音页面的网址与类型、已加载作品信息、用户主动选择的素材地址、公开互动数据、发布文案和公开一级评论。上述内容仅用于用户主动发起的下载、整理、暂停继续和导出。

插件只在 www.douyin.com 页面运行，并访问页面提供的抖音素材域名完成用户主动选择的下载；不会建立跨网站浏览历史，不出售数据，也不用于广告、信用评估或跨网站画像。

插件只处理当前账号能够正常访问的公开内容，不绕过登录、验证码、访问控制、签名或平台限制。“已加载”与“已下载”不代表平台内部绝对全量。当前稳定评论范围为一级评论。
