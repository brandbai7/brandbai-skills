电商采集大师

把你有权访问的公开资料，按需整理到本地。

电商采集大师 · BrandBAI，原名“BrandBAI 采集大师”（早期名称“BrandBAI 下载助手”）。本次更名保留原 B 标志、原更新渠道与原数据边界。

支持平台与能力

  • 抖音：单条视频／图文、封面、可提取音频、发布文案、公开基础数据和作品一级评论；当前已加载列表可选择整理。挂车作品打开当前商品后，可按页面实际信息整理商品资料；商品评价与作品评论为独立任务。
  • 天猫／淘宝：当前商品资料、主图、详情图、可见视频、参数、实际可售规格和交易区信息快照；评价与问大家分开保存，问大家每题只保存列表当前展示的一条回答。
  • TikTok：视频／图集、封面、页面可用音频、发布文案、基础数据与公开一级评论；支持已加载列表的选择整理和用户主动启用的本机双语导出。
  • 小红书：手动打开笔记后按需保存公开素材与文案；主页、搜索只整理当前已加载卡片。评论需手动展开并加载后读取，不自动滚动、翻页、批量打开笔记或托管账号。
  • 微博：单条微博及首页、主页、搜索结果中当前已加载内容的选择整理，保存公开正文、素材、来源与基础数据；评论按当前页面支持范围独立保存。

如何使用

  1. 安装扩展，阅读并确认《使用与数据说明》。
  2. 由你打开并正常访问受支持的页面；需要登录时，在平台官方页面自行登录。
  3. 查看侧栏识别到的当前对象、可用资料和缺口，选择要保存的内容。
  4. 按需下载 ZIP 或导出 Excel。支持自动滚动的评论／评价任务可查看进度、暂停及在原对象与筛选不变时继续。

平台标注总数不等于当前已保存数量。部分结果可以导出，但不能当作全部历史数据。商品资料、商品评价、作品评论是不同任务；不把不同商品或筛选下的结果混合。

数据与使用边界

结果保存在本机，不上传给 BrandBAI；不执行发文、点赞、关注、私信、购买或支付，不提供账号托管，不绕过平台限制，不保证账号不受风控影响。仅负责采集整理，不自动生成账号研究、商品匹配或投放结论。

公开免费版本默认供个人学习、研究和合法的非商业用途使用。企业内部使用、客户项目、对外交付、转售、代采集、会员服务或其他商业用途，应另行取得杭州岂飞品牌管理有限公司书面授权。采集不代表取得第三方内容的转载或商业使用授权。
