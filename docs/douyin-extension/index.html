当前免费版能力

01

抖音作品与评论

整理单条作品、主页或搜索结果中的素材、基础数据、文案与公开一级评论。

02

小红书笔记资料

整理单篇笔记的正文、可用素材与公开一级评论，并支持列表页批量资料。

03

小红书跨词采集

合并多个关键词的当前可见结果，按笔记 ID 去重并保留来源与作者汇总。

04

天猫/淘宝商品资料

整理商品概览、参数、可见规格、主图、详情图与页面提供的视频。

05

评价与问大家

从用户主动打开的完整评价或问答界面整理当前可访问内容，并保留完成状态。

06

结构化本地交付

在本机生成 ZIP、Excel 与说明，区分成功、页面未提供、失败与部分完成。

重要的数据处理说明

插件处理的网站内容包括：用户主动操作时，当前抖音、小红书及天猫/淘宝页面已经展示并可访问的公开作品、笔记、商品、素材地址、互动数据、评论、评价、追评和问答，以及完成下载所需的本地任务状态。

插件只在受支持的平台页面运行，并访问这些页面提供的必要素材域名完成用户主动选择的下载；不会建立跨网站浏览历史，不出售数据，也不用于广告、信用评估或跨网站画像。

插件只处理当前账号能够正常访问的内容，不绕过登录、验证码、访问控制、签名、付费限制或平台技术措施。“当前已加载”“当前可见已到底”和“平台全部内容”是不同状态，未获取内容不会被推测为完整。
