更新后为什么仍显示旧名称？

确认安装的是新版本并重新打开侧栏；对升级前已经打开的平台标签页刷新一次。商店介绍或宣传图变化不会替代安装包更新。不要为了更名卸载扩展或清理历史任务。商店更新仍应使用原项目。

商品面板打开后显示什么？

识别到当前商品后，侧栏应显示商品资料与商品评价，而不是作品评论。若商品身份、页面结构或对象归属暂不能确认，保持待确认状态；请核查当前页面，不要把旧商品信息当作新商品资料。

为什么商品评价按钮不能开始？

先在平台商品面板打开“商品评价”，再核对侧栏是否识别到当前评价区域。商品资料、作品评论和商品评价分别保存；不要在读取期间切换商品或筛选。支持的任务可暂停、继续及导出已保存评价表。

平台显示上千条，为什么保存数量更少？

平台标注数量、页面已加载数量、可靠识别数量和已保存数量不同。仅保存页面实际提供的结果；未确认完整时会提示部分结果。不得将阶段导出理解为全部历史评价。

小红书为什么不自动滚动？

小红书采用手动浏览、按需保存的流程。请自己打开笔记、滚动和展开评论；扩展只整理当前已加载内容，不自动翻页、遍历笔记或托管账号。出现验证、限制或异常提示时停止操作，按平台官方流程处理；没有“保证不封禁”的承诺。

文件保存在哪里，删除记录会删除文件吗？

文件通过 Chrome 保存到本机下载目录或你指定的位置。扩展任务记录、下载结果与 Chrome 下载历史独立；删除任务记录不会自动删除已保存文件。撤回确认可停止受控处理，详情见隐私政策。

翻译不可用怎么办？

TikTok 可选双语依赖兼容 Chrome 的本机能力；不支持或失败时保留原文，不自动转用云端翻译服务。首次模型准备由 Chrome 管理。

反馈问题时提供什么？

请提供扩展版本（侧栏底部）、平台和页面类型、操作步骤、实际提示，以及去除私人信息后的截图。可使用界面已有的诊断导出入口。不要发送密码、Cookie、验证码、私信、订单或收货信息。公开来源链接也请先核查是否含敏感参数。
