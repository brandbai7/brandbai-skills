# 电商采集大师 v0.11.217 试用更新

本版本通过 GitHub 预发布安装包提供，供手动安装与试用。GitHub 发布与 Chrome Web Store 审核、上架及自动更新是不同渠道；本说明不表示该版本已通过商店审核。

## 字幕可以整理成继续工作的资料

- 默认“只提字幕”：保留字幕文字与采样时间，可复制、修改或导出 TXT，不为脚本工作包保存配图。
- 主动选择“字幕＋关键画面”后，保留字幕对应的采样画面。同一句内画面变化明显时可保留多张；无法保留时明确标注，不拿其他句子的画面替代。
- 脚本工作包包含图文浏览页、可编辑 Excel、字幕文字及来源说明；选择配图时附带对应画面。内容作用、品牌改写和拍摄备注等工作列供后续填写，不是自动生成的分析结论。
- 作品素材与脚本工作包分别导出。有可用作者信息时，文件名包含作者昵称和作品标识，便于与原素材对应；商品资料、作品评论与商品评价仍需独立选择。

## 本次稳定性修复

- 同一视频发生清晰度变化时，按每张画面的实际尺寸处理，避免把清晰度切换误判为来源不符，也避免混用裁剪坐标。
- 完成主扫描后，可选补查若因媒体超时或解码失败无法继续，保留已读内容，继续能够在本机缓存内完成的字幕整理，并明确记录未补查位置。
- 修复可选补查失败与缓存封存之间的后台检查竞态，避免已有缓存的整理被错误中断。来源、作品身份、页面控制权、授权与用户停止检查仍然有效。
- 区分原始画面文字、已整理字幕和仍有缺口的结果，避免把“已经读到文字”直接显示为“字幕完整完成”。

## 切换页面时请看任务提示

读取画面期间应保留原视频页面；界面明确提示“画面已读取，可以切换页面”后，可切换页面并继续本机识别。切换到另一条作品时，不把上一条字幕放在当前作品结果中。已保存的文字可从本机记录查看；删除本机记录不会自动删除已导出的文件。

## 使用和证据边界

仅识别 3 分钟内短视频的画面文字，不识别声音，不上传视频、画面或待识别文字给 BrandBAI 或外部 OCR 服务。采样时间用于回看，不是精确字幕轴。

识别可能有错字、重复、遗漏，或混入包装文字、花字。候选和缺口会保留，但不代表每处错误都能自动找出。已处理完任务与全片准确、完整不是一回事；用于对外发布或商品表述前，仍应回看核对。本版本不作准确率或百分之百完整性承诺。

配套抖音下载 Skill v0.6.6 使用单独冻结的 v201 本地识别运行组件；其本地输入、导出格式和验证范围与本插件不同。插件的网页操作和 Excel 脚本工作包能力不应写成 Skill 已支持的相同能力。

仅处理有权使用的公开内容，不绕过登录、验证码、访问权限或平台限制。软件的商业使用授权与第三方内容的使用权分别处理，沿用既有许可与授权要求。本版本的自动化回归、受控场景测试与安装包校验不等于所有真实网页或所有视频均已验收。
