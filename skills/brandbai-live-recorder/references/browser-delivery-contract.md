# 浏览器 ZIP 交付合同 · 0.22.0

0.22.9 当前任务卡可按交付 ID 展示文件回执，状态来自交付中心；任务中的旧快照不能代替浏览器完成确认。查询失败保留最后确认信息并明确连接状态，禁止显示为实时进度。重试已有文件不得重新启动采集，商品切换不得将其他商品的回执显示在当前商品下。

0.22.7 展示入口改为“下载记录”，历史默认折叠、分批显示，选中任务单独展开；“下载完成”仍只取 Chrome 完成且字节校验一致，采集完成不能代替文件交付确认。不删除旧记录，不改变下载、重试或缓存规则。

本合同优先于历史版本的插件保存位置说明。仅改变交付，不增加采集、分析、商品视频下载或交易能力。

## 用户流程

- 插件不要求首次选目录；直播录制、目录、单商品、评价各自一次任务交付一个 ZIP。录制拆分的视频仍在同一个包中。沿用原命名与商品身份字段。
- 调用 Chrome downloads，filename 只提供文件名，saveAs=false、conflictAction=uniquify；实际路径与可能的浏览器安全／组织策略提示由浏览器决定。不读取浏览器配置猜路径，不修改浏览器设置。
- 采集结束先整理 ZIP，再下载。采集完整性与文件传输状态分别记录；部分资料也可交付，但不得称全部取得。
- “下载与保存”统一显示进度、暂停／继续／取消、重试已有包、在文件夹中显示。重复点击或后台重启不得重复派发同一次下载。
- 关闭侧栏后，已经提交本机助手的任务和已启动的浏览器下载继续。仍在网页读取、尚未提交的商品资料保留原页面采集约束，不承诺关闭商品页仍可补齐。
- 关闭整个浏览器不停止本机媒体录制；页面互动在关闭期间缺失。下次打开插件显示待下载任务，由用户点击下载，不批量回放所有历史下载。

## 缓存和恢复

助手在私有状态目录 browser-deliveries 中按随机任务 ID 建立独立 work 缓存，绝不直接移动或清理旧保存目录。录制 ZIP 使用 ZIP64 流式存储，不再次压缩视频；保留源 TS 和已转封装 MP4，因此需要足够临时磁盘空间，浏览器目标盘也需空间。

每个 delivery.json 持久记录交付状态、相对路径、大小、来源请求、下载尝试和票据哈希。不把服务令牌、请求头、文件票据或私有交付记录装入客户包。

下载失败、取消、浏览器关闭或助手重启时保留资料。助手重启后的未完成采集，只能打包已经取得的部分内容，不自行重新采集或录制。任务请求指纹防止同一个请求 ID 被替换成另一商品。

正常成功下载后至少保留本机缓存 24 小时，在后续创建任务时清理；只删除自有已交付缓存、拒绝符号链接／目录联接，历史文件和未交付资料不自动删。存在互动尾批更新时保留。缓存条目上限 2000，空间不足明确失败，不假报成功。

录制结束等待约 5 秒后，在事件锁内快照互动账本；之后再到的尾批标记“可下载更新后的资料包”，不修改浏览器已保存的 ZIP、不擅自第二次下载。

## 接口和安全

插件受鉴权 API 请求增加 X-BrandBAI-Delivery: browser-zip。未传入此头的 Skill／CLI 或旧 API 保留目录与原设置语义，不接受浏览器指定绝对路径。

| 接口 | 含义 |
| --- | --- |
| GET /v1/deliveries | 已知任务包和状态，不含私有路径或票据 |
| POST /v1/deliveries/{id}/prepare | 准备或恢复该任务的已有文件 |
| POST /v1/deliveries/{id}/claim | 原子认领一次浏览器下载；显式 retry 才重试 |
| POST /v1/deliveries/{id}/report | 校验尝试 ID、Chrome 下载 ID、状态和接收字节数 |
| POST /v1/deliveries/{id}/missing | 显式核对浏览器记录不存在后释放失败尝试 |
| GET /v1/deliveries/{id}/file/{attempt} | 使用独立票据头流式发送 ZIP，支持 Range |

票据仅绑定扩展身份、任务、尝试和固定 ZIP，24 小时过期，服务器只存 SHA-256 哈希。票据在请求头而非 URL；文件下载不携带全局服务密钥。非扩展网页 Origin、错身份、错票据、任意路径请求必须被拒绝。文件发送成功本身不代表浏览器完成；仅接受浏览器 complete 且接收字节与包大小一致的报告。

扩展后台只检索这次任务的精确下载 URL，并检查 byExtensionId；不浏览、修改其他下载。downloads 和 alarms 是新增权限；站点权限不扩张，不采集 Cookie、不读取收货地址，不参与购买。浏览器会话 watch 只记当前主动启动的任务；新浏览器会话不自动下载历史 ready 包。

## 验收边界

分别验证：数据／身份不回归、ZIP CRC 和大文件流式输出、默认下载目录、重复点击不重复下载、暂停与取消、重启恢复、部分状态、晚到互动、浏览器真实完成及窄侧栏排版。合成测试不能代替客户真实直播和商品页面验收。
