# BrandBAI 直播助手界面体系

0.22.9 使用紧凑品牌头部，目录与当前商品按对象状态分配主次按钮。录制运行时，结果卡移到设置前；底部按钮可停止当前任务，重复点击不重复提交。状态轮询只更新变化内容，保留操作节点及键盘焦点。评价开始必须预览就绪且匹配当前商品；连接失败的唯一进度卡显示最后确认条数，停止失败等操作错误仍可见。当前任务通过交付 ID 取得独立文件回执，未获浏览器完成确认不得写成下载完成；重试文件只调用已有交付，不触发重新采集。静态说明、历史下载继续折叠，原采集与身份逻辑不变。

0.22.8 操作区只放当前对象、设置、按钮和动态反馈。规格说明、评价范围、数据关联、录制影响与后续分析用途统一放在两工作区共用的底部“帮助与联系”，默认折叠；公众号和邮箱仅在使用者点击时复制，不读取剪贴板、不上传。开启互动时保留一句前台与同账号提示，连接、停止、部分结果等即时状态保持可见。侧栏重开先还原旧进度、连接恢复后更新真实数量并清除该查询的过期提示，不制造第二个采集任务。本版只更新扩展，运行助手保持 0.22.7。

0.22.7 历史浏览器下载统一在“下载记录”，默认折叠。点击“查看下载”仅展开选中的任务，其余收进“历史下载”，每次显示 5 条，可继续展开；列表自身限高，不拉长整个商品页。当前商品不重复展示其他商品的浏览器下载结果，旧版目录输出仍保留折叠兼容入口。结果的长说明可展开，商品 ID 收入“查看识别到的图片与规格”，字段不删除。对外用“已读取／等待返回评价页／继续读取／下载完成”，不把读取落盘当浏览器下载完成。停止和失败原因保持可见，不用折叠隐藏阻塞操作。

0.22.5 当前商品只显示属于该身份的下载反馈。已结束的其他商品资料／评价结果放在单商品卡下方“其他商品的下载记录”，默认折叠，保留下载入口；运行中或身份未确认的任务不擅自清空。切换商品仅清除旧消息，不在每次轮询时清除当前错误。主图总数未知采用中性“完整性待核验”，不能将数量未知误写成确定缺图。继续使用蓝白配色与同商品共享身份，不新增分离商品选择入口。

0.22.4 评价运行中只保留一个实际保存进度；隐藏静态预览条数、重复启动按钮与目标设置。未达目标要明确原因，并在原页检查点有效时提供继续补采；结果区说明累计包不与旧包相加。图片成功和规格待确认分开表达，不用笼统“未收齐”掩盖已完成部分。商品下载对弹窗观察的影响直接说明，不承诺互动不受页面状态影响。本轮须配套更新助手，以下仅改视觉的发布说明属于 0.21.4 历史记录。

扩展 0.21.4 对齐电商采集大师 0.11.160 的品牌视觉，不合并业务或权限。

## 共享基础

- `assets/chrome-extension/design-tokens.css` 是直播扩展的统一样式变量入口：品牌蓝 `#176ff2`、深蓝 `#0f5fd4`、冷灰底 `#f4f7fb`、白色卡片、深灰文字 `#182235`；绿色完成、黄色待确认、红色错误或停止操作。颜色以外保留文字状态。
- 同源 BrandBAI 标志；品牌标志及名称受品牌许可约束，不因源码许可取得商标许可。
- Windows 优先微软雅黑；主体 13px，帮助 11.5–12px，区块标题 16px，单商品标题 15px，可自然换行，不隐藏商品身份或失败信息。
- 卡片圆角 14px，控件圆角 10px；常规卡片内边距 16px，间距 12px。主操作蓝底、次操作白底蓝边、停止操作红字；禁用不采用整块透明淡出。
- 侧栏 320px 起核验；窄幅表单转单列。底部录制操作区按实际高度预留内容空间，避免多行反馈遮住内容。支持键盘焦点和减少动画偏好。

## 用户旅程

固定品牌头部 → 直播录制／商品资料切换。商品页先展示本场目录，再在同一“当前研究商品”卡内分别下载图片规格与买家评价。两种下载仍共用真实商品 ID 或受限观察身份。目录不强制先下载；单商品不因界面变化重新识别成另一个商品。

首选保存位置、读取中、停止保存、已完成、部分未确认、连接失败均沿用现有状态来源；不得因统一配色把部分资料改为完整。商品视频能力未在此版本增加。

## 发布和后续合并

本次仅改扩展界面及展示消息颜色；本机服务仍为 0.21.3。原来的助手无需重装或重启，插件重新加载后显示新界面。可复用样式变量和组件语义，不复制电商插件的后台、账号状态、权限、采集入口或任务记录。真正合并需单独设计权限、能力注册和任务迁移。
