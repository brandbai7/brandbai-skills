# BrandBAI 直播采集助手界面体系

适用功能版本：0.22.13。与电商采集大师使用同源品牌视觉，但不合并后台、权限或任务。

## 共享基础

- `assets/chrome-extension/design-tokens.css` 为样式变量入口：品牌蓝 `#176ff2`、深蓝 `#0f5fd4`、冷灰底 `#f4f7fb`、白色卡片、深灰文字 `#182235`。状态同时用文字解释，不只靠颜色。
- 统一名称“BrandBAI 直播采集助手”及同源标志；品牌许可与源码许可分开。
- Windows 优先微软雅黑。商品名称、状态和错误自然换行；侧栏 320px 起核验，窄幅表单转单列，交互控件可用键盘访问。
- 主操作蓝底，次操作白底，停止／结束保留明确文字。暂停和结束按钮至少 44px 高，反馈不遮挡操作，支持减少动画偏好。

## 页面与当前任务

紧凑品牌头部 → 直播录制／商品资料。商品资料先展示本场目录，再在同一“当前研究商品”内分别保存图片规格与评价。目录不是单商品下载的前置步骤；两类单商品资料共用真实商品 ID 或受限页面身份，不增设独立选品入口。

操作区只放当前对象、必要设置、按钮和动态反馈。静态解释统一放在底部“帮助与联系”，默认折叠；公众号与邮箱仅在用户点击时复制，不读取剪贴板或上传。互动开启时保留一句前台与同账号提示。阻塞操作的连接、停止失败或部分结果原因不能藏进帮助。

录制运行时，当前状态优先于设置。状态轮询只更新变化内容，保留操作节点及键盘焦点；重复点击不重复提交。侧栏重开先恢复原任务，再核对最新状态，不凭本地旧条数宣称仍在保存，也不创建新任务。

## 评价：一个进度，三个操作

- **开始读取评价**：当前评价预览就绪且与商品匹配后才启用；按当前筛选和排序读取，不显示条数预设。
- **暂停读取**：停止自动滚动，保留同一任务，不生成结束包。清楚显示“已暂停”，以及继续或结束的选择。
- **继续读取**：只恢复仍有效的原页面、商品与筛选；不把新页面评价追加给旧商品。
- **结束并下载**：停止读取、整理本次累计包，再显示浏览器交付状态。失败可重试结束，不重复开始采集。

运行时只有一处实际条数“已读取 N 条”，不保留静态预览数、不显示 200 条分母或重复任务卡。读取期间不叠加“文件是否已下载”的卡片，进入整理／下载阶段再展示该状态。具体状态机和保护预算以 [评价合同](product-review-contract.md) 为准。

“当前列表已读完”“平台有折叠评价”“已暂停”“文件已下载”必须区分。停滞、离开页面或保护时限不是读完证据；列表读完也不是全量历史评价。暂停和连接异常保留最后确认数量，不能把仍在滚动当作保存成功。

## 商品结果与下载记录

图片完整性、套餐组成、购买规格分别说明。没有展示规格不推断为单 SKU；主图总数未知不写成确定缺图，视频位置不算漏下载图片。已成功的部分可使用，未知字段仍保留在清单。

当前商品只显示属于该身份的结果。其他商品的已结束结果放入折叠记录，活动或身份未确认任务不擅自清空；切换商品不反复清除当前错误。历史下载统一折叠，每次展开有限条目并限高，不在操作区连续堆卡。

浏览器默认下载位置，无首次单选文件夹步骤。以当前任务交付 ID 核对文件回执，只有浏览器确认完成才显示“文件已下载”；资料整理完成和下载完成分开。重试文件使用已有包，不重新采集，历史文件不覆盖。

## 维护边界

文案与视觉调整不得把部分结果改为完整，不改变同商品身份、来源范围或许可。复用样式和组件不等于授权迁移另一插件的账号状态、权限、采集入口或任务记录。

功能升级按 [版本说明](release-notes.md) 核对配套版本；不要沿用旧版本“只改界面、无需更新助手”的结论。本次文档同步不修改运行程序。
