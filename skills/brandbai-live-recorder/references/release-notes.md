# BrandBAI 直播录屏 Skill 0.22.10

首次发布直播录屏 Skill 独立 GitHub 版本，汇总已实现的录制、页面采集和资料交付能力。

## 能做什么

- 公开抖音直播按设定时长录制，可选画质和视频分段；无浏览器模式支持多个不同直播间独立录制。
- 按需记录直播评论、弹窗商品与公开人数指标；依赖原直播网页持续更新。
- 不用先录屏，也能独立保存商品编号目录、单商品主图和详情图、页面可选规格及价格图片对应。
- 同一商品可分别下载图片规格和买家评价，保留共同身份字段；评价有目标条数、停止保存与原页条件下手动继续。
- 浏览器版每次任务一个 ZIP，使用浏览器默认下载位置；采集完整性与文件下载结果分别说明。

## 这次同步

整理 Skill 入口、使用路线和客户能力说明，清理旧版保存位置与读取时限等冲突说明。功能基线为浏览器扩展 0.22.9、本机助手 0.22.7；本次包内扩展版本同步为 0.22.10，采集行为不变。已有上述基线用户不必为文档更新重启助手或重新加载插件。

## 使用边界

商品和评价采集需要配套 Chrome 插件与本机助手，不是无浏览器批量抓取。目标评价数不保证读满，直播互动不保证全量；在线人数是同时在线快照，不是进房人数或留存率。商品视频、评价图片及评价视频下载尚未支持。

本次不自动进行真实直播采集；本地测试、隔离页面验证和发布包校验不替代具体直播间的实时完整性核验。下载、云端转写和分析分别发起；云端转写需单独同意上传。
