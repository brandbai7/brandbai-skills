# BrandBAI 直播录屏助手 0.22.10

本版同步 Skill 入口和客户说明，界面及采集行为沿用 0.22.9，兼容 0.22.7 本机助手。已有这组版本无需因本次文档更新重载插件或重启助手。录制进度在上方，底部可停止保存；历史记录与帮助默认收起。当前任务的文件下载结果与资料是否收齐分开，只有浏览器确认完成才显示“文件已下载”。

BrandBAI 蓝白侧栏。目录在前，图片规格与买家评价共用一张商品卡；各自可独立下载，同商品身份保留。真实 ID 未取得时不按名称猜配。

评价读取时暂时切走页面，会显示“等待返回评价页”，返回原商品及筛选后继续。最多等待 5 分钟，且不超过本次 3／10 分钟时限；仍未返回则保存已有评价，可在原页面继续。等待期间不读取或滚动页面，不改变直播录制。

历史下载集中收在“下载记录”，默认不展开。点击“查看下载”只展开本次任务，其余记录收起；商品卡不连续摆放其他商品的历史结果。旧文件不删除。

## 浏览器默认 ZIP 下载

录制、目录、商品、评价每次任务一个 ZIP，不再在插件选保存目录。使用浏览器默认下载位置，位置在浏览器设置中更换；旧文件与原设置不移动。无浏览器 Skill／CLI 仍按目录输出。

“下载记录”显示打包、下载和完成状态。仅 Chrome complete 且接收字节吻合才显示“下载完成”；资料是否收齐单独说明。支持暂停、继续、取消、重试已有包、在文件夹中显示。同名保留新副本，不覆盖。

关闭侧栏后助手与已启动下载继续；关闭整个浏览器不停止本机媒体录制，但页面互动缺失。下次打开可主动下载待交付包，不自动重放历史任务。仍在页面采集的商品资料需要保留商品页，重开侧栏继续保存。

失败与取消保留本机资料，不重新采集。成功下载后至少保留临时副本 24 小时，后续任务才清理已交付的自有缓存；不删除旧保存目录。录屏 ZIP64 流式存储，不重新压缩视频，保留源 TS 和 MP4，需要临时空间。晚到互动提供更新包提示，不擅自第二次下载。

## 安装升级

需要 Chrome 114 或更新版本及 0.22.7 助手。已有 0.22.7 助手无需重装。全部录制及下载停止后，在扩展管理页重新加载原插件，再刷新直播页并打开侧栏。新用户加载直接含 manifest.json 的内层文件夹。历史文件和保存设置不迁移。

0.22.6：减少无关页面节点的重复扫描，商品／评价预览错开读取，重连时重复加载不再重建采集器；读取超时不等同于页面未连接。新的商品资料、目录、评价 ZIP 不显示待核字段和内部编码；未知名称用“直播间”，缺商品标题直接省略，同名保留不同副本。身份关联信息仍在包内。

搜索页里的直播支持带／不带 www 的抖音地址。若提示“需要允许读取当前页面”，点击“允许识别抖音直播”，在 Chrome 中确认后立即重新识别。可选授权覆盖抖音站点，插件只处理明确打开的直播入口；不会自动录制或下载。不授权也可在当前直播页点击工具栏插件图标临时使用。切页或撤回权限后重新核对，不沿用旧房间。

助手按需启动；未处理的浏览器确认不被定时关闭。失败允许重试，不在恢复连接后自动重做已失败的业务请求。

## 采集边界

断流会在原截止时间内最多重试两次，保留中断前后片段并标记缺口。录制期间可切换普通标签，但请保持原直播页打开，不要用同账号在其他地方进入直播间；浏览器冻结、账号冲突或休眠可能中断评论。没有新观察不代表没人评论。不提供无限自动重连、循环监控、自动分析或成交归因。

- 插件仅一个活动直播间，切换时显示另一个直播间正在录制，结束解除占用，不自动录新房间。
- 默认 30 分钟、不分段；提前结束并保存不取消独立下载。
- 同步记录直播互动需主动开启，记录可见脱敏评论、商品卡和公开指标，不承诺全量。05_直播互动 提供 Markdown、CSV、完整性清单；原始 JSONL 保留。
- 当前录制页节能暂停时限定恢复播放，不抢其他标签焦点，失败和缺口说明。
- 目录每轮最多新增 100 条，缺号最多约 12 秒复查，候选号独立标推测待核验，不写入确认编号或商品身份。
- 单商品补齐主图／详情图，全部可选规格最多 40 个组合，核对价格和对应图片并恢复原选择。不完整保留部分状态。商品主图视频尚未支持。
- 评价默认目标 200 条，可选 50／500；50 条每轮最多 3 分钟，200／500 条每轮最多 10 分钟。只按当前筛选与排序，买家化名，历史规格保留原文，附图只计数。可停止并保存；未达目标时，原商品、筛选和未刷新页面的检查点仍有效才可继续，生成新累计包，旧包不覆盖、数量不相加。

## 权限与安全

保留 activeTab、storage、sidePanel、scripting、downloads、alarms；downloads 与 alarms 仅用于本机 ZIP 交付与状态续接。新增可选的 https://www.douyin.com/* 与 https://douyin.com/* 站点权限，只有点击授权按钮才申请。不申请所有网站、tabs、cookies、webRequest 或 debugger 权限。只检查本次精确 URL 且 byExtensionId 相同的下载，不枚举其他下载。

文件通过限定三个本机端口传送，独立短期文件票据在请求头，不携带全局服务令牌，不放进 URL 或导出包。不读取收货地址、支付信息，不购买、抽奖或自动分析。
