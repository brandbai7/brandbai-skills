# BrandBAI 直播采集助手 0.22.16

录制公开直播，也能独立整理直播商品目录、商品图片与规格、买家评价。0.22.16 修正中断后的结果提示：直接说明页面转入后台等原因，不再把尚未开始的规格核对显示为读取失败。采集流程不变；已安装 0.22.14 助手时，只需更新扩展，无须重启助手。更早版本请使用完整客户包同步更新。

## 安装与更新

- Chrome 114 或更新版本，Windows 配套本机助手。
- 新安装：加载直接包含 `manifest.json` 的文件夹。
- 旧版升级：所有录制、读取和下载结束后，更新原文件夹并重新加载扩展，再刷新直播页。无需移除旧插件或新装第二个。
- 产品原称“BrandBAI 直播录屏助手”。原安装路径、设置、连接方式和历史文件不变；Skill 调用名仍为 `brandbai-live-recorder`。
- 助手按需启动。首次使用按 Chrome 提示打开“BrandBAI 直播采集助手”。未授权时不会启动录制任务。

## 使用

“直播录制”选择时长、画质和是否分段。需要评论、弹窗商品和在线人数时，开始前开启同步记录。保持原直播页打开并持续更新，不用同一账号在其他地方进入直播间。视频、页面互动和采集空档分别记录，不承诺互动完整。

“商品资料”中，目录、单商品图片规格、评价分别发起，不要求先录屏。图片规格和评价共用当前商品身份；没有真实商品 ID 时不能按相似名称跨页面合并。参数区套餐组成与可购买规格分开整理；商品视频暂不支持。

评价自动向下读取，不预设条数。“暂停读取”保留本次进度；原商品、筛选与页面未变时可“继续读取”；“结束并下载”交付本次累计 ZIP。读到可见列表末尾或平台折叠提示时自动结束。加载停滞、切页后久未返回或触发保护限制会保留进度并暂停，不冒充读完。平台折叠评价不在采集范围内。

关闭侧栏不主动停止任务。仍在读取商品或评价时保留原页面。助手暂时失联只表示状态未同步，不要重复开始。刷新、换商品或换筛选后不能把新内容混入原任务。

## 下载与保存

浏览器版每次任务一个 ZIP，使用浏览器默认下载位置。读取、整理文件和浏览器下载是不同阶段，只有浏览器确认完成才显示“文件已下载”。下载记录默认收起；已有包下载失败可重试，不必重新采集。同名保留新副本，不覆盖历史文件。

无浏览器 Skill 的录制仍按独立场次目录输出，不走浏览器下载。

## 权限与范围

权限沿用原版：activeTab、storage、sidePanel、scripting、downloads、alarms，以及限定的本机连接与抖音直播页面权限。普通抖音站点权限可由用户主动授权；也可在当前直播页点击工具栏图标临时使用。不增加所有网站、cookies、webRequest 或 debugger 权限。

只保存有权访问的公开内容，不读取收货地址、支付信息，不购买或发评论。在线人数是采样时同时在线数量，不是独立访客或留存率。评价使用买家化名，附图只计数，不下载评价图片或视频。采集不自动分析或转写；云端转写须另行授权。

功能边界和完整性记录以资料包说明为准。合成测试不代表已验证所有真实直播页面。

不提供无限自动重连、循环监控、成交归因或自动分析。
