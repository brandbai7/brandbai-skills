# BrandBAI 直播采集助手｜安装与快速使用

版本 0.22.16。录制、商品目录、单商品图片规格、买家评价分别发起；浏览器每次任务生成一个 ZIP，使用浏览器默认下载位置。

本版修正读取提前结束后的提示，直接说明页面转入后台等原因；尚未开始核对规格时，不再提示“规格尚未读完”。已取得图片全部保存不等于整页资料完整。已安装 0.22.14 助手时，只需在全部任务空闲后更新原插件文件夹并重新加载，无须重启助手；更早版本请同步更新插件和助手。历史下载、保存设置和采集流程不变。

支持从“综合搜索”进入直播间；需实际打开直播，普通搜索结果页不能直接录制。

## 安装

### 在浏览器中使用

1. 从客户安装包运行 `02_安装采集助手.cmd`。
2. 解压 `BrandBAI直播采集助手浏览器插件_0.22.16.zip`。
3. Chrome 打开 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”。
4. 选择直接包含 `manifest.json` 的内层 `BrandBAI直播采集助手浏览器插件` 文件夹，不选外层客户包或 ZIP。
5. 打开公开抖音直播间，点击工具栏“BrandBAI 直播采集助手”。

浏览器版需要 Windows、Chrome 114 或更新版本及配套本机助手。首次启动本机助手时，按浏览器提示确认打开。需要读取当前页面时，点击“允许识别抖音直播”并处理浏览器确认；不授权常驻访问也可用工具栏图标临时授权。

更新程序前先停止全部录制与下载。重新加载扩展后，如旧页面仍未识别，可刷新直播页再打开侧栏。不要在活动任务中重启本机助手。

从旧版升级请继续使用原插件加载文件夹，只更新其中的文件，再点击扩展管理页的“重新加载”。旧文件夹名称可保留，不需要移除并安装第二个插件。Windows 启动入口同步改为新名称；Skill 调用名仍是 `brandbai-live-recorder`。

### 在 AI 工具中使用 Skill

将 `BrandBAI直播采集助手Skill_0.22.16.zip` 导入支持 Agent Skills 的工具，或按该工具说明安装。解压后的 Skill 根目录直接包含 `SKILL.md`。

无浏览器录制需要 Python 3.10+、FFmpeg／FFprobe 与 StreamGet 运行环境；首次检查和准备依赖由宿主按权限完成。商品和评价等页面采集仍需配套 Chrome 插件与本机助手；不是只装 Skill 就能在所有 AI 工具内直接抓取页面。

## 录制直播

提供公开直播间链接并选择时长。默认标清、30 分钟、一个视频；需要多个视频时再开启分段。到时自动结束，也可提前停止并保存。

需要对照评论、弹窗商品和人数时，在开始前主动开启“同步记录直播信息”，按需要选择类型。原直播页需保持打开并持续更新；建议保持前台，不要用同账号在其他设备或窗口进入直播间。

关闭侧栏不主动停止录制。原直播页冻结、退出或关闭，互动可能缺失，即使视频仍在录制；网页状态、视频状态和互动条数会分别记录。短暂断流会受限尝试恢复，但不会补回缺失内容。

先看 ZIP 中的 `00_直播记录说明.md`。视频、评论、弹窗商品和直播指标分区整理；弹窗商品是卡片记录及已有缩略图，不是完整商品详情。

## 保存商品与评价

### 本场商品目录

在“商品资料”点击“下载商品目录”。列表已展开就直接读取，未展开时尝试打开“全部商品”；正在看单商品时先关闭详情。

保存编号、名称、展示价格、1 张缩略图和可见讲解标注，不逐个进入详情。每轮最多新增 100 条，没读完可明确继续。编号被遮挡时尝试复核；未确认的编号不会凭顺序写成事实。

### 当前商品的图片与规格

打开想研究的商品并核对名称，在“商品详情”点击“下载图片与规格”。自动读取主图、详情图、公开参数与页面可选规格的价格和图片，结束后核对恢复原选择。

请保持商品页打开，不手动切商品或规格。商品视频暂不支持；单规格需有明确证据，未展示规格不能当作只有一款。图片是否收齐与规格是否确认分别说明。

商品参数区若有套餐切换，会另外整理各档名称、组成、数量和公开参数，并核对恢复原选择。套餐内容与可购买规格分开保存，不把通用展示价格或主图当作每档的独立价格或专属图片。

### 同一商品的买家评价

在同一商品打开“商品评价”，自行选好筛选和排序，再点击“开始读取评价”。自动向下读取，不用设置数量。

“暂停读取”保留进度，不提前导出；回到原商品、原筛选且页面未刷新时，可以“继续读取”。点击“结束并下载”，把本次累计评价打成一个包。读到当前列表末尾也会自动结束并下载；平台折叠的评价不在采集范围内。

关闭侧栏不主动停止任务。切走评价页会先等待返回；长时间未返回、连续读取较久或加载停滞时保留进度并暂停，可选择继续或下载。换商品、换筛选或刷新后，不会把新评价混入旧任务。

买家使用化名；保存文字、历史所购规格、已显示追评和商家回复、附图数量，不下载评价图片或视频。商品资料与评价可分别下载，通过包内商品身份关联；没有真实商品 ID 时不能凭相似名称跨页面合并。

## 下载与保存

浏览器版不另选文件夹。流程为“读取／录制 → 整理 ZIP → 浏览器下载”，只有浏览器确认完成才显示“文件已下载”。下载记录默认折叠，点击查看本次结果；失败可重试已有包，无需重新采集。

下载位置到浏览器设置中更换。同名保留新副本，历史文件不覆盖。网页还在读取时需保留原页面；关闭侧栏后再打开可恢复任务信息。助手暂时失联只代表状态尚未同步，不要重复开始。

无浏览器 Skill 按独立场次目录保存，不走浏览器下载。支持多个不同房间并行录制，不包含多路网页互动。

## 使用边界与联系

- 只处理你有权保存的公开内容，不绕过登录、验证码或访问限制；不购买、发评论或读取收货、支付信息。
- 下载不自动转写或分析。指定录屏可另行转写，云端处理需要单独同意上传。
- 在线人数是采样时同时在线的数量，不是进房人数、独立访客或留存率。
- 部分结果保留实际数量、停止原因与缺口，不把目标数量或平台总数当作已下载数量。
- 卸载使用客户包的 `03_卸载采集助手.cmd`，不删除历史视频。
