# 微博普通版导出格式

## 目录结构

```text
BrandBAI_微博普通版_<对象>_<日期>/
├─ 01_账号资料.xlsx
├─ 02_微博清单.xlsx
├─ 03_评论明细.xlsx
├─ 04_转发扩散.xlsx
├─ 05_搜索与话题快照.xlsx
├─ 06_微博素材/
├─ 07_采集说明.md
└─ data/
   ├─ accounts.jsonl
   ├─ posts.jsonl
   ├─ comments.jsonl
   ├─ reposts.jsonl
   ├─ assets.jsonl
   ├─ search_snapshots.jsonl
   ├─ hotlist_snapshots.jsonl
   ├─ profile_selection.json
   ├─ run_manifest.json
   └─ delivery_manifest.json
```

## 01_账号资料.xlsx

- `账号总览`：账号 UID、名称、认证、简介、关注、粉丝、微博数、规范链接、采集时间和完成状态。
- `主页选择`：微博 ID、主页位次、是否置顶、选择原因、页面摘要和规范链接。
- `达人快照`：仅单微博详情包生成；保存当前详情页已展示或加载的公开作者字段、快照时间和来源微博，不进入主页补齐，不下载头像。

## 02_微博清单.xlsx

- `微博总览`：微博 ID、作者 UID、正文、类型、发布时间、地区、来源、浏览／转发／评论／点赞快照、原微博关系、选择语境、规范链接和状态。
- `话题与提及`：微博 ID、类型、顺序和页面原文。
- `素材索引`：素材 ID、微博 ID、类型、顺序、状态、本地文件、脱敏来源 URL、尺寸、字节数和 SHA-256。
- `完整性`：每条微博的完成状态与说明。

## 03_评论明细.xlsx

保存评论 ID、ID 类型、微博 ID、父／根评论 ID、层级、匿名作者 ID、可选显示名、原文、时间、地区、点赞、声明回复数、保存回复数、展开状态、观察排序、各排序首次位次、采集时间和最后观察时间。`采集状态` 表同时保存页面可见排序、已经跑完的排序及每个排序的终止依据。

## 04_转发扩散.xlsx

保存转发 ID、源微博 ID、上游转发 ID、匿名作者 ID、可选显示名、转发文案、时间、地区、互动快照、传播链状态和采集时间。

## 05_搜索与话题快照.xlsx

- `结果位次`：快照 ID、查询类型、查询词、排序、筛选、位次、微博 ID、账号 UID、摘要、推广标记、采集时间和范围状态。
- `话题上下文`：快照 ID、话题名、页面可见阅读／讨论／主持等原文和采集时间；没有观察到的字段留空，不推断。
- `超话资料`：超话 ID、名称、分类、帖子数、成员数、今日签到、排行、可见分区、本次采集分区和快照状态。
- `热搜榜单`：榜单类别、页面顺序、排名原文、数字排名、词条、热度、分类、标签、置顶／特殊行标记、词条入口和快照状态。

## 隐私与第三方内容

- 评论者和转发者默认稳定化名；账号博主保留页面公开名称和 UID，便于来源回溯。
- 默认不保存登录资料、Cookie、请求头、验证码、手机号或带鉴权参数的 URL。
- 微博正文、评论、转发、图片和视频仍属于相应权利人，不因导出而进入 BrandBAI 源码许可证。

## 分析边界

普通版不增加情感、口碑、粉丝质量、明星商业价值、品牌匹配、传播归因或销量结论。后续分析必须用稳定微博 ID、评论 ID、转发 ID 和快照 ID 回链原始证据。
