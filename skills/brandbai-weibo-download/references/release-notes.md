# Release notes

## 0.1.2

- 修复评论列表尚未滚到底部时，因连续三次页面节点无增长而提前结束的问题。
- 页面同时提供“按热度”和“按时间”时分别采集，按评论 ID 合并，并保存各排序首次位次。
- 适配微博虚拟评论列表：以持久化评论 ID 总集去重，不把当前 DOM 节点数量当成已保存总量。
- 回复入口改为逐次重新定位、循环展开；声明回复数仍大于保存数时继续保留部分完成状态。
- 新增登录限制、滚动预算耗尽、排序激活失败、双排序完成等独立状态与逐排序终止依据。

## 0.1.1

- 用微博主页自身可见响应中的公开 `isTop` 标记识别置顶微博，修复新版页面不再显示“置顶”文字时的漏判。
- 账号主页、评论和转发改用渐进滚动，避免虚拟列表直接跳到底部后漏掉中间记录。
- 修复转发页签定位和转发记录解析，阻止评论行被误收为转发。
- 回复完整性改为基于已持久化记录总集计算；声明回复未全部保存时，总任务明确标为 `partial_reply_not_expanded` 并写入警告。
- 使用第二组已登录公开明星营销样本，对明星本人、当前工作室、品牌官宣、代言关键词、普通话题、明星超话热门／最新、相关 UGC 评论与转发、实时热搜完成全链路复测。

## 0.1.0

- 新增单微博、账号主页、关键词搜索、普通话题、明星超话和热搜榜单六类入口。
- 账号主页支持“全部当前可见置顶＋最近 N 条非置顶微博”的稳定选择合同。
- 保存正文、话题、提及、互动快照、图片、封面和页面可见视频。
- 新增一级评论、可见回复和可见转发记录，分别保留回复展开和传播链完整性状态。
- 搜索与话题结果冻结查询词、排序、筛选、采集时点和页面可见位次。
- 超话保存超话 ID、社区指标原文、页面可见分区和分区帖子位次；已验证热门与最新分区。
- 热搜主榜和文娱榜保存排名、热度、标签、采集时点与词条入口；置顶／特殊行作为数字排名之外的额外记录。
- 明星本人、工作室、品牌官微和粉丝内容账号主页均已完成真实页小样本验证；账号认证字段仅从主页头部读取，未观察到时留空。
- 默认对评论与转发作者使用稳定匿名 ID；不会导出 Cookie、浏览器登录资料或带鉴权参数的媒体地址。
- 生成五张普通版 Excel、素材目录、采集说明、原始结构化文件和可选 ZIP。

本版本已在已登录的可见 Chrome 中完成单微博、明星主页、工作室、品牌官微、粉丝内容账号、关键词、普通话题、超话热门／最新、热搜主榜／文娱榜、评论、回复、转发和素材的小样本验证。完成状态只对应采集时点页面可见范围，不承诺平台绝对全量、热搜历史峰值或完整传播链。
