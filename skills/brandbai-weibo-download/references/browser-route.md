# 微博浏览器路线

## 稳定入口

1. 明确微博链接：`https://weibo.com/<uid>/<post-id>`。
2. 账号主页：`https://weibo.com/u/<uid>`，首版选择全部当前可见置顶加最近 N 条非置顶。
3. 关键词搜索：`https://s.weibo.com/weibo?q=<query>`，需要正常登录微博。
4. 话题搜索：把主题词规范为 `#主题词#` 后进入微博搜索页。
5. 明星超话：`https://weibo.com/p/100808.../super_index?mod=TAB`，选择页面当前可见的热门、最新或精华等分区。
6. 热搜榜单：`https://s.weibo.com/top/summary`；文娱榜等分类使用页面公开 `cate` 入口。

## 登录资料夹

- 使用独立私有 Chrome 资料夹，不复制系统 Chrome Cookie。
- 资料夹不能位于仓库、同步盘、交付目录或 ZIP 内。
- 第一次运行增加 `--login-wait 180`，用户在可见窗口内手动登录。
- 验证码、二维码确认、风险提示和访问确认只能由用户手动完成。

## 页面操作

- 只滚动页面当前可见列表，不调用隐藏签名、私有接口或绕过访问控制。
- 主页、搜索、超话、评论和转发列表分别记录滚动次数、无新增次数与终止依据；热搜榜单保存当前表格快照。
- 页面结构变化时标记 `partial_selector_drift`，保留已保存数据并允许续跑。
- 搜索结果进入单微博后必须回到冻结的结果列表，不重新解释位次。
- 热搜数字排名按 `--hotlist-limit` 保存；置顶和特殊行作为额外记录，不占数字排名名额。
- 榜单词条不是微博详情。若要继续采集词条内容，另以词条运行普通话题或关键词搜索。

## 素材

- 图片只接受微博和新浪公开媒体域名。
- 视频只在页面暴露可保存的 HTTP(S) 地址时下载；只有 `blob:` 地址时记录 `not_observed`。
- 对外 JSON、Excel 和说明不保存带鉴权查询参数的媒体 URL。
- 下载失败不影响已采集文字字段，但微博状态必须降级为 `partial_asset_failure`。

## 宿主差异

脚本路线需要本地 Python、Chrome、可见桌面和文件权限。没有本地浏览器能力的宿主只能生成 Dry Run、读取已有采集包或提示用户改用 BrandBAI Chrome 插件；不能声称已经在线采集。
