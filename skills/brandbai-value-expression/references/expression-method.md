## 1. 判断对象

卖点可视化不是美术包装、图片生成或商品真实性审计。它把上游已确认的商品价值翻译成用户能看见、听见、理解、想象和记住的感知语言：

```text
商品事实／FABE／职责单一的商品价值
→ 用户真正想知道的问题
→ 目标感知
→ 六条翻译路径
→ 职责单一的感知原子
→ 画面、动作、声音、字幕、道具协同
```

先继承商品价值，再设计感知方式。好拍、显眼、包装漂亮、页面已有画面多或某个参数容易演示，都不能重新排序P0。

## 2. 六条翻译路径

每个准备沟通的P0/P1/P2必须完整扫描六条路径，再选择1条主路径和1—2条辅助路径。

| 路径 | 回答的问题 | 常用方式 |
|---|---|---|
| 数字化 | 有多少、多久、几次、到手多少、值不值 | 数量、时间线、容量与参照物 |
| 感官化 | 用户如何提前想象味道、气味、触感、温度、声音或状态 | 质感近景、动作原声、人物反应与感官词 |
| 差异化 | 相对旧习惯、普通方案或真实替代有什么不同 | 同框、动作、结果或选择成本差异 |
| 情境化 | 在什么真实触发时刻、任务与环境中发生 | 生活片段、使用前后状态与任务现场 |
| 证据化 | 什么页面事实、包装、演示、报告或结果解除具体顾虑 | 凭证、标签、实物、演示与对照物 |
| 人格化 | 商品如何进入生活方式、关系或身份 | 选择理由、关系语言、人物状态与使用习惯 |

主路径解决最关键用户问题，辅助路径增加体验、关联或信任。未选路径不能省略，必须写“本轮不优先”或“不适用”及理由。路径名称本身不是交付；必须落到具体感知和呈现轨道。

## 3. 十二类感知原子

六路回答“一个价值怎样翻译”，十二类槽位回答“整件商品有没有漏掉必要感知资产”。二者同时执行：

| 资产组 | 槽位 | 主要任务 |
|---|---|---|
| 欲望建立 | 01 商品识别／构成开箱 | 一眼看懂商品是什么、里面有什么 |
| 欲望建立 | 02 一级识别锚点 | 一眼认出商品，不承担P0 |
| 欲望建立 | 03 规格、数量、产地或结构连看 | 把抽象品质翻译成具体参照 |
| 欲望建立 | 04 工艺到可见状态／结果 | 让工艺落到用户看得见的变化 |
| 欲望建立 | 05 味觉、触感、气味或使用体感 | 提前想象体验并判断是否适合 |
| 欲望建立 | 06 省步骤／使用方便 | 看见商品替用户省掉哪些动作 |
| 欲望建立 | 07 使用方法／多种用法 | 清楚知道怎么用和需要什么条件 |
| 欲望建立 | 08 到手量、使用周期或价值权衡 | 理解一份商品如何进入一次或一段使用 |
| 阻力解除 | 09 具体检测／证明对应具体顾虑 | 一条证据只回答一个真实问题 |
| 阻力解除 | 10 生产、体系、品牌或质量信息 | 建立可查、可归属的信任 |
| 阻力解除 | 11 商品身份、适用边界与买前确认 | 减少误购、误解、预期落差和退款 |
| 氛围连接 | 12 场景、人格与日常仪式 | 进入生活，但必须与实质价值共同出现 |

十二类是扫描槽位，不要求机械凑满，也不代表内容顺序。适用则建立VIS，不适用写明理由。十二槽位全部适用不是质量分；不得为了“填满”把没有独立事实、问题或感知任务的重复资产改成适用。

## 4. VIS原子规则

每个VIS：

1. 只有一个主价值；共享素材只能登记辅助价值。
2. 只完成一个主要决策任务：看懂、相信、觉得适合、觉得值、选对或知道下一步。
3. 回指至少一个上游事实，并继承上游不能证明什么。
4. 一个价值可以对应多个VIS；每个可沟通价值至少有一个VIS。
5. 商品识别与核心价值感知分开。一级识别锚只负责认出商品。
6. VIS编号只用于资产索引，不是镜头、图片或播放顺序。
7. 普通版最多选择5个核心VIS；先覆盖全部可调用P0/P1，再判断P2是否真正解除当前购买阻力。P2环保态度、体系信息、动态权益等没有品牌战略或用户证据时默认保留为辅助资产，不为凑满5张机械进入核心卡。不能让同一价值的重复卡挤掉尚未覆盖的P0/P1，全量资产仍保留在数据底稿。
8. 声称“一包／一袋里同时有这些内容物”时，使用当前SKU未拆封单包连续倒出全部内容物，并明确不补料、不换包、不拼接；预摆样品只能说明原料形态，不能证明单包构成。
9. 包数、单包克重与建议用水量可以按已确认事实呈现；“整周、几天、一个月”、使用频次、减少补货、一次买够或够用一阵必须另有上游事实直接出现同类语义，不能由包数、容量、重量或件数自行换算。上游事实若声明到手件数、套组清单或装箱内容冲突，停止调用并先返回商品价值 Skill。

## 5. 多轨呈现

每个VIS必须完整填写五条基础轨：

| 轨道 | 必须回答 |
|---|---|
| 画面 | 用户具体看见什么，景别与注意重点是什么 |
| 动作 | 人或商品发生什么可见变化 |
| 声音 | 动作原声、环境声、人物反应、口播语气，或有理由的静音留白 |
| 字幕 | 画面最终要被理解成哪一句人话 |
| 道具 | 什么参照物帮助理解数量、状态、差异或场景 |

场景、特效/BGM、商品/包装/商品页承接属于扩展必判轨。扩展轨可以写“不使用，以及原因”，不能留空。

多轨不是互不相干的清单：动作必须让画面发生变化，声音强化动作或感受，字幕解释该怎样理解，道具提供参照，商品承接确保用户认出并选对。

## 6. 页面已有与新增建议

页面详情既是上游事实来源，也是已有沟通素材。先盘点页面已经怎么说、怎么拍、用户能感知什么、哪些可直接复用、哪些仍有缺口。上游 `EX-` 直接继承；本轮补充商品素材的传播语言与画面形式使用 `PEX-` 登记，并回指上游事实。`PEX-` 不能新增商品事实。

页面出现过只证明品牌采用了该表达，不证明有效。新增VIS默认是“建议假设／未测试”；只有真实素材、直播或页面版本与对应数据、评论、观察窗口和必要对照对位后，才能升级为候选或已验证资产。

称量、测量、盲测、连续使用或报告原件只在能明显增强理解、比较或信任时作为可选增强，不是公开详情页进入沟通翻译的统一前置门槛。详情页里的报告截图只能称为“详情页截图／页面局部”，只有实际取得且登记为 `original_document` 的文件才能称“报告原件”。页面画面中真实可见的支架、容器或背景可以如实登记为页面视觉元素，但不能据此声称已取得对应线下实物；不得一处登记为可见元素，另一处又把它写成“实际不存在”。

当上游事实标记 `exact_fields_verified=false` 时，可以继续使用上游已确认的页面公开主张、检测项目、结果和结论，但不能把未核验的单位、限值、报告编号、日期、方法标准或认证编号写进字幕、道具、必须保留项或验证任务。不得用“误用提醒里写了禁止”来抵消正文中的越界表达。

验证任务必须分别写清对照版、测试版、唯一变量、指标获取方式和回写判断。证据画面、两版固定字幕、验证任务和指标必须回答同一个语义问题；安全性检测不能被用来降低或抵消孕哺禁忌，也不能替代稳定性/失活证据。唯一变量是证据画面时，两版字幕和其余轨道保持一致；验证连续单包证明时，两版都使用当前SKU真实单包，不得用预摆盘作为“一包构成”的对照证据。留存、完播、点击等平台行为指标与评论复述等语义指标分开读取；没有数据连接关系时不得合并成一个指标。未登记样本量和统计检验方法时不得使用“显著性”判断，只记录观察方向。

single_variable 必须写成一个已锁定的具体变量和两个明确水平，不得用“截图A或截图B”“任选一种”等备选表达，也不得同时改变字幕字号与出现节奏、画面证据与字幕主张等多个维度。症状分层、以说明书或医务人员指导为准、禁忌、注意事项、警示和适用边界属于发布护栏，对照版与测试版都必须保留，不能通过删掉护栏来验证“解释是否更清楚”。

外部品类、竞品、普通款或传统方案的同框、对照和对比属于比较性表达。只有关联上游事实已登记同题比较对象、比较口径和直接证据时才可设计；当前商品的医疗器械身份、认证、规格或页面自述不能替代外部比较证据。没有直接比较证据时，只比较当前商品自身的两种呈现方式，不把未入账的外部对象放入画面。

## 7. 内容对象接口

VIS可以标注适用于种草、直播引流短视频、挂车成交短视频、直播间和商品页，以及必须保留和可调整的轨道。

本阶段只提供原子和调用条件，不排列完整内容。业务目标、受众决策、账号或达人语法、具体载体、SKU入口和交易承接齐全后，才进入内容组装。

## 8. 禁止越界

本 Skill 不得：

- 重新选择P0、改变P1/P2或修改上游事实；
- 把页面显眼、好拍、已有素材多或包装符号写成核心价值；
- 来源只列举多个用途，却改写成“一瓶搞定/解决全部”；
- 只有画面联想或味觉文案，却写成用户当下“闻得到/能闻到/香气扑鼻”的真实嗅觉体验；
- 字幕说“三条工艺”，画面却混入第四个场景，或把背景、工艺和证据混作同一计数；
- 仅凭当前商品身份或资质，把普通款、传统方案、同类或竞品作为同框对照物；
- 把二选一素材或两个呈现维度伪装成一个变量，或在对照版中删除必要安全/适用护栏；
- 把页面已有表达、建议VIS或一次测试写成已验证资产；
- 脱离详情页原意扩写功效、绝对承诺、跨SKU结论或第一人称体验；
- 在缺少业务目标、人群、账号/达人、内容对象和交易承接时生成确定方向、开头钩子、完整信息链、脚本、达人原话或动态CTA；
- 把VIS编号、十二槽位或价值层级当作固定播放顺序；
- 伪造样本量、阈值、指标结果、归因和成功结论。
