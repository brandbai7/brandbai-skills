# BrandBAI Value Expression 0.1.11

## 0.1.11 紧凑方案语义预检

- 在确定性编译前拦截把商品标题、SKU ID、规格等多个高密度字段合并为一条页面表达；
- 页面截图、页面检测报告局部或公开展示没有 `original_document` 依据时，禁止在 VIS 与验证任务中称为报告、证书或文件原件；
- 面向客户的限制、页面表达、六路、槽位、VIS、验证与缺口字段不得泄露 `SF-` 等内部资产 ID；
- 保留最终语义校验器，以上错误从“最终生成报告后再返工”前移到紧凑方案 Dry Run。

## 0.1.10 原子表达与脚注继承

- `EX-/PEX-` 不得把上游已经拆开的高密度标签字段重新合并成一个页面表达；
- 页面正文带脚注标记时，必须同时保留对应脚注原文并在表达边界中说明作用范围；
- VIS 调用带脚注表达时，必须在 `must_keep/misuse/boundary` 继续保留脚注或限定语；
- 校验器新增高密度字段合并、孤立脚注和下游丢失脚注边界拦截。

- 新增 `compile_value_expression_plan.py`：把审阅后的紧凑方案确定性编译为 PEX、六路、槽位、VIS、验证与缺口账本，避免模型按顺序错配槽位编号或一次写入大账本。

## 0.1.9 否定边界与普通版状态清理

- 周期、补货和统计门禁只识别正向主张；`不得推导`、`不写`、`没有`等否定边界不再误报，也不再被当成上游正向支持。
- 页面已有表达在普通版统一显示为“页面已有／未验证”，不再暴露结构化账本内部枚举。
- 保持0.1.8逐价值工作包、确定性合并、真单变量与必要医疗护栏合同不变。

## 0.1.8 逐价值工作包与确定性合并

## 0.1.8 逐价值工作包与确定性合并

- 新增逐价值输入摘要和固定六路骨架，模型每轮只处理一个价值的六条路径，不在同一上下文累积完整大账本；
- 新增 `merge_value_expression_ledger_parts.py`，确定性合并 PEX、六路、槽位、VIS、验证和缺口分包，并校验稳定 ID 与预期计数；
- 工作包强制位于正式交付目录之外，正式交付不残留生成器、修复脚本或调试文件；
- 明确 60 秒持续推理但目标账本仍为空时停止大事务，改用小包续跑，只重做失败分包。

## 0.1.7 真单变量与必要护栏

- 拦截“截图A或截图B”等未锁定具体素材的二选一变量；
- 拦截字号与节奏、画面与字幕等多个呈现维度同时变化的伪单变量；
- 禁止在任一实验版本中删除症状分层、说明书/医务人员指导、禁忌、注意事项、警示或适用边界。

## 0.1.6 外部比较证据边界

- 拦截没有上游直接比较证据的外部品类、竞品、普通款或传统方案同框/对照/对比；
- 明确当前商品的身份、资质或自身事实不能替代外部比较证据；
- 验证任务在没有比较证据时只允许比较当前商品自身的两种呈现方式。

## 0.1.5 语义强度与核心卡优先级

- 来源只列用途时拦截“一瓶搞定/解决全部”等充分性升级，要求改成“对应/可用于”；
- 上游没有气味或真实嗅觉证据时拦截“闻得到/能闻到/香气扑鼻”，保留为画面联想或待验证表达；
- 核心卡改为优先覆盖P0/P1，P2只有在解除真实购买阻力或具有战略/用户证据时进入，允许少于5张；
- 增加数字字幕与画面对象数量一致性要求，避免把背景、工艺和证据混作同一计数。

## 0.1.4 多样本上游冲突与验证语义收敛

- 阻断上游已声明冲突的到手件数、套组清单和装箱内容进入路径、VIS 与普通版；
- 拦截由包数、容量、重量或件数自行推导周期、频次、补货与“一次买够”；
- 校验证据画面、固定字幕、验证任务和指标语义同题，禁止安全检测抵消禁忌或替代稳定性证据。

## 0.1.3 核心资产与验证计划收敛

这是核心资产选择、真实单变量与版本追踪收敛版：

- 可沟通价值不超过5个时，普通版核心卡各覆盖一个主价值，一级识别锚不占核心名额；
- 证据画面测试保持两版字幕一致，单包构成验证的对照与测试均来自当前SKU真实单包；
- 没有样本量或统计检验方法时拦截“显著性”判断；
- 拦截由包数自行推导的“整周、几天、一个月”等使用周期；
- 页面真实可见装置如实登记，但不升级为报告原件或线下实物；
- 初始化器支持显式递增 `output_version`，并校验其与 `value_expression_id` 一致。

## 0.1.2 页面表达与证据完整性

这是页面表达与证据完整性修订版：

- 新增本轮补充商品素材的 `PEX-` 页面表达账本，普通版页面盘点必须由data确定性生成；
- 区分详情页截图与原始报告，未登记 `original_document` 时禁止称“报告原件”；
- 拦截上游未核验的单位、限值、报告字段和认证标识精确名称进入呈现资产；
- 单包内容物证明必须保留未拆封单包、连续展示和不补料／不换包条件；
- 验证任务新增对照版、测试版、指标获取方式和判断规则，拦截方向冲突与不可直接观测的混合指标。

## 0.1.1 元数据兼容

这是 SkillHub 等宿主的元数据兼容性修订版：

- 将 `SKILL.md` 的 `description` 改为直接可提取的单行文本；
- 同步 Skill 运行版本和独立安装包；
- 上游继承、六路翻译、十二类感知槽位、VIS、证据边界及验证状态合同保持不变。

## 0.1.0 首发能力

- 读取有效的 BrandBAI 商品价值底座，不改写商品、SKU、事实、FABE 和 P0/P1/P2；
- 逐项扫描六条价值翻译路径与十二类感知槽位；
- 形成画面、动作、声音、字幕、道具、场景、特效／BGM 和交易承接等原子呈现；
- 区分页面已有表达、分析建议、待验证假设和已验证资产；
- 输出普通用户可读方案、结构化交接数据和单变量验证计划；
- 不生成达人匹配，也不把未测试建议包装成已验证效果。
