# BrandBAI Value Expression 0.1.1

这是 SkillHub 等宿主的元数据兼容性修订版：

- 将 `SKILL.md` 的 `description` 改为直接可提取的单行文本；
- 同步 Skill 运行版本和独立安装包；
- 上游继承、六路翻译、十二类感知槽位、VIS、证据边界及验证状态合同保持不变。

## 0.1.0 首发能力

- 读取有效的 BrandBAI 商品价值底座，不改写商品、SKU、事实、FABE 和 P0/P1/P2；
- 逐项扫描六条价值翻译路径与十二类感知槽位；
- 形成画面、动作、声音、字幕、道具、场景、特效／BGM 和交易承接等原子呈现；
- 区分页面已有表达、分析建议、待验证假设和已验证资产；
- 输出普通用户可读方案、结构化交接数据和单变量验证计划；
- 不生成达人匹配，也不把未测试建议包装成已验证效果。
