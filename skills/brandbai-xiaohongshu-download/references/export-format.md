# 普通版导出格式

## 目录

```text
BrandBAI_小红书采集_对象_YYYYMMDD/
├─ 01_笔记清单.xlsx
├─ 02_评论明细.xlsx
├─ 03_搜索快照.xlsx
├─ 04_笔记素材/
│  └─ <note_id>/
├─ 05_采集说明.md
└─ data/
   ├─ run_manifest.json
   ├─ notes.jsonl
   ├─ comments.jsonl
   ├─ assets.jsonl
   ├─ search_snapshots.jsonl
   └─ delivery_manifest.json
```

## 工作簿

### 01_笔记清单.xlsx

- `笔记总览`：笔记 ID、标题、正文、作者、类型、发布时间、地区、指标快照、置顶状态、规范链接、采集时间和完成状态。
- `话题明细`：一行一个话题或提及，保留原始顺序。
- `素材索引`：素材 ID、类型、顺序、尺寸、文件、哈希、来源 URL、下载状态和失败原因。
- `完整性`：账号选择、笔记内容、素材和评论的独立状态。

### 02_评论明细.xlsx

- `评论明细`：评论 ID、父评论 ID、根评论 ID、层级、匿名作者 ID、评论原文、时间原文、地区原文、点赞、声明回复数、实际保存回复数和展开状态。
- `采集状态`：每条笔记的显示评论数、保存一级评论数、保存回复数、终止信号和完成状态。

### 03_搜索快照.xlsx

- `结果位次`：搜索快照 ID、关键词、标签页、筛选、位次、笔记 ID、标题、作者、推广标记、采集时间。
- `相关查询`：同一快照下页面可见的“大家都在搜”等相关查询词及顺序。

## 空值规则

- 页面明确显示 0：数值写 `0`。
- 页面未展示：值留空，状态写 `not_visible`。
- 尚未尝试：状态写 `not_requested`。
- 公开不可用：状态写 `not_available`。
- 采集异常：状态写 `failed` 并保留简短失败原因。

不得用空白代替 0，也不得用 0 代替未观察到。
