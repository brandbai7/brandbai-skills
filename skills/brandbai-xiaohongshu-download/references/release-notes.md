# BrandBAI Xiaohongshu Download 0.4.2

## 本次修复

- 修复“编辑于 04-20”被拆成发布时间“编辑于”和地区“04-20”的字段错误；仅在页面明确出现 IP 属地或尾部确实为地区文本时才分列；
- 将同一视频的多个清晰度／CDN 备用地址合并为一个逻辑素材，按候选顺序回退下载，不再重复写入多个视频；
- 图片和 MP4 的实际宽高改为读取最终成功保存的文件字节，不再沿用页面候选标注；
- 兼容媒体容器延迟加载与页面结构回退；交付目录名含小数点时，ZIP 名称不再被截断；
- 补充日期与最终 MP4 尺寸的合成回归测试，并以真实公开单篇完成前向验收。

## 0.4.1

- 修复动态照片／视频播放器只显示 `blob` 时漏掉公开页面内嵌 MP4 地址的问题；
- 媒体恢复只接受 `xhscdn.com` 白名单内的 MP4，临时查询参数仅用于内存下载，交付继续去参数；
- 首次登录默认预留 180 秒，并在目标页面可见后立即继续，不再固定等待完整倒计时；
- 单篇仅使用规范链接而无法进入详情时，返回可执行的完整链接提示；
- 运行清单保留安全的 `CollectionError` 说明，避免只留下无法诊断的错误类型。

## 0.4.0

### 本次升级

- 明确区分单篇完整资料包与账号主页／搜索列表页批量下载；
- 单篇可进入详情读取标题、正文、话题、素材、互动快照与页面可见一级评论；
- `batch` 模式只保存当前列表卡片可见字段、封面、选择位次与上下文，不逐篇打开详情，降低低速与访问风险；
- 新增确定性 ZIP 打包和 SHA-256 校验；
- 未请求或没有数据时不再生成空评论、空搜索工作簿；
- 增加稳定笔记 ID、来源 URL、列表位次、字段范围和显式完成状态；
- 新增列表批量不进入详情、交付范围和打包的合成回归测试。

## 0.3.0

- 支持关键词搜索批量采集前 N 条笔记和搜索快照；
- 支持单篇笔记、账号主页与搜索结果普通版 Excel 交付。
