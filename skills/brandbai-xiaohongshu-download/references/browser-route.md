# 浏览器路线

## 允许路线

使用用户可见、正常登录的 Google Chrome。首次运行使用独立私有登录资料夹，由用户手动完成登录、验证码和访问确认；同一批任务复用同一浏览器上下文。

完整链接中的临时导航上下文只在内存中使用；持久化时只保留规范笔记或主页链接，不得把 `xsec_token`、Cookie、请求头或浏览器资料写入计划、manifest、Excel 或 ZIP。

## 页面路由

1. 明确单笔记：进入详情页，读取正文、指标、用户所选素材；请求评论时再读取当前详情页评论区。
2. 账号主页批量：记录账号公开字段，滚动发现全部当前可见置顶和最近 N 条非置顶，冻结列表卡片后直接导出；不得逐篇进入详情。
3. 搜索批量：冻结关键词、标签页、筛选、时间和原始可见位次，读取列表卡片和封面；不得逐篇进入详情。
4. 列表卡片需要完整正文、全部素材或评论时，先让用户明确选择笔记，再改走单笔记路线。

批量列表模式不跳详情，是为了缩短任务、减少频繁页面导航，并保持“当前列表页观察快照”的证据边界。

单笔记播放器若只显示 `blob` 地址，可以从同一公开页面的内嵌数据中恢复当前笔记的 `xhscdn.com` MP4 候选；只使用白名单媒体域，查询参数仅在当前内存下载中使用，持久化前必须删除。不得读取 Cookie、请求头或浏览器存储来恢复媒体地址。

首次运行默认给用户 180 秒手动登录。每秒检查一次目标是否已可见；目标出现或登录完成并刷新成功后立即继续，不等待完整倒计时。

## 禁止路线

- 不读取或导出 Cookie、请求头、浏览器密码、账户私密数据或签名参数。
- 不实现验证码绕过、访问控制绕过、签名生成、隐藏限速规避或无界并发。
- 不把 DataTool 或其他第三方扩展作为公开 Skill 的运行依赖。
- 不在登录资料夹、仓库和交付目录之间互相嵌套。
- 不把列表页未展示的正文、素材或评论写成已采集。

页面崩溃或导航中断时可以重建工作标签页，但必须沿用原输出目录、稳定 ID 和 checkpoint 续跑。
