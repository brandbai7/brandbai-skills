# 浏览器路线

## 允许路线

使用用户可见、正常登录的 Google Chrome。首次运行使用独立私有登录资料夹，由用户手动完成登录、验证码和访问确认；同一批任务复用同一浏览器上下文和一个工作标签页。

单笔记优先接收用户从当前可见页面地址栏复制的完整链接。链接里的临时页面导航上下文只在内存中用于打开页面；持久化时只保留 `https://www.xiaohongshu.com/explore/<note_id>`，不得把 `xsec_token` 写入计划、manifest、Excel 或 GitHub。

## 禁止路线

- 不读取或导出 Cookie、请求头、浏览器密码、账户私密数据或签名参数。
- 不实现验证码绕过、访问控制绕过、签名生成、隐藏限速规避或无界并发。
- 不把 DataTool 或其他第三方扩展作为公开 Skill 的运行依赖。
- 不在登录资料夹、仓库和交付目录之间互相嵌套。

## 页面路由

1. 单笔记：先确认笔记 ID 和当前页面可见内容类型，再读取正文、指标、素材与评论区；只给规范链接但无法打开时，回到正常登录或完整地址栏链接路线。
2. 账号主页：先记录账号信息，再滚动发现置顶和最近 N 条，冻结选择集合后逐条访问。
3. 搜索结果：先冻结关键词、标签页、筛选和采集时点，再按可见位次发现前 N 条；不要先去重再重排位次。
4. 评论：优先从已冻结的笔记清单进入；每条笔记处理完再进入下一条。

页面崩溃或导航中断时可以重建工作标签页，但必须沿用原输出目录、稳定 ID 和 checkpoint 续跑。
