# BrandBAI 抖音基础采集验收合同

本合同只验收作品采集和评论采集，不验收语义分析或达人结论。

## 作品采集

### 输入

- 一个达人主页 URL、搜索结果页 URL、明确作品 URL 列表，或 BrandBAI 选择文件。
- 达人主页可使用最近非置顶作品数 N；默认 5。搜索页和选择文件保留页面类型、搜索词、来源排序与选择顺序。
- 一个位于输出目录之外的持久 Chrome 登录资料夹。

### 选择

- 保留主页当前可见的全部置顶作品。
- 另选发布时间最近的 N 条非置顶作品。
- 同一作品 ID 只出现一次；置顶作品不占 N。
- 保留平台真实 `/video/` 或 `/note/` 路径。
- 插件 Excel 或选择 JSON 按完整作品 ID 去重；找不到的指定 ID 单独记录，不能静默缩小范围。
- 搜索页“全部”只表示本次页面观察到的作品；优先使用插件导出的选择文件固定范围。

### 每条作品的最低字段

- 作品 ID、类型、达人名称、标题、发布时间。
- 点赞、评论、分享、收藏及页面可得的推荐数。
- 是否置顶、选择原因、选择顺序、来源链接。
- 本地素材目录、各素材下载状态和整条作品状态。

### 单作品达人快照

- 最终交付仅含 1 条明确作品时，可从该作品页已经展示或加载的数据生成“达人快照”。
- 可保存昵称、抖音号、稳定达人 ID、主页链接、简介、粉丝数、累计获赞、快照时间和来源作品。
- 未展示和确认的字段必须留空，不能用 `0` 表示未知；不为补字段自动进入达人主页，也不下载头像。
- 快照是采集时点公开事实，不构成达人画像、粉丝质量、商业价值或合作建议。

### 完成条件

- 视频：主视频已保存；图文：全部当前可得图片已保存。
- 用户请求的封面、原声和发布文案已保存，或分别明确记录公开不可用；未选择的素材记录为 `not_requested`。
- 文件不为空，音频扩展名与实际文件类型一致。
- 汇总“素材文件”只统计实际写入或确认已存在的文件；素材明细保留公开不可用等资产记录，两者不得混为同一数量。
- `works.json` 与 `download_manifest.json` 的数量和状态一致。
- 选择文件缺少媒体地址且作品页也未返回可用元数据时标记 `partial_metadata_unavailable`，不得写成完整。
- `--assets none` 是合法的数据模式，不要求创建空素材目录。

## 一级评论采集

### 输入

- `works.json`、一个或多个作品 URL/ID，或达人主页可见 N 条作品。
- 默认只采集一级评论；二级回复必须显式开启。

### 每条评论的最低字段

- 作品 ID 与真实作品链接。
- 评论 ID、根评论 ID、父评论 ID和层级。
- 隐私化评论者、原始评论文本、时间、点赞、回复数和可得 IP 标签。
- 是否作者回复、ID 来源和采集时间。

### 完成条件

- 每个目标作品均有独立进度记录。
- 一级评论分页收到明确终止信号；不能只凭当前屏幕没有新评论判断结束。
- SQLite、CSV、JSONL、manifest 和报告的总数与状态一致。
- 断点审计必须按作品读取 SQLite 的实际行数和进度，不得把整库缓存总数错误归到单个作品。
- CSV、JSONL、manifest、报告和 Excel 均区分平台 ID 与页面兜底 ID，并给出分项数量。
- 页面只提供相对评论时间时保留可见原文，不推算或伪造绝对日期。
- DOM 兜底只代表当前可见一级评论，不可据此推断全量或二级回复完成。
- 平台显示评论数、一级已采集数、一级评论声明的回复数和实际采集回复数分别报告；不得用一级评论中的回复数字段冒充已采集回复。

## 当前不纳入完成条件

- 二级回复全量。
- 评论语义标签、D1 证据包、达人画像、商品适配和商业结论。
- 平台内部不可见、已删除、权限受限或本次页面未返回的数据。
