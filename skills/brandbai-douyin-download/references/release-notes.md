# BrandBAI Douyin Download 0.6.0

## 0.6.0

- 新增显式 `--product-reviews`：对一个明确挂车作品，按顺序保存作品、关联商品公开资料与当前商品评价；商品评价与作品评论独立保存。
- 商品评价模块基于 BrandBAI Chrome 插件 v0.11.156，支持当前评价容器自动滚动、进度记录、逐批落盘后确认、暂停及身份核验后的去重续跑；不需要安装浏览器扩展。
- 默认限额 200 条、200 次滚动、600 秒；预算停止、未识别条目及身份变化保持部分结果，不把页面评价总数当成已保存数。
- 新增普通交付 `05_商品评价.xlsx` 及独立原始数据、状态文件。未知商品 ID 不允许跨页面实例强行续跑合并；临时签名评价图片链接不进入导出。
- 修复已有商品弹层可错绑作品、规格／物流字段可混入个性化收货信息，以及非图片响应或已有损坏文件可误报成功的问题。
- 同步单 Skill 发布包、安装入口、使用说明与合成回归；没有把离线通过或插件截图表述为本 Skill 真实平台端到端验收。
- 商品视频文件、全 SKU 成交矩阵、逐 SKU 主图和商品评价媒体 ZIP 仍不在支持范围内。

## 0.5.0

- 新增显式 `--commerce-detail`：只允许恰好一个明确作品，冻结作品 ID 并暂停播放后，从当前作品商品入口读取公开商品卡；
- 商品面板在文档级门户中识别，连续稳定后才采集，读取前后都校验作品 ID，防止连播或弹层切换造成跨作品错绑；
- 可保存公开展示的标题、店铺、价格／销量快照、物流服务、可见规格、参数与商品图片；商品图片限制为抖音商品图片域名并按真实文件签名纠正扩展名；
- `01_作品清单.xlsx` 在该模式下新增“商品概览”“商品规格”“商品参数”“商品素材”，商品图片进入作品目录的 `商品资料/`；
- 默认模式仍只观察商品入口，不自动点击；隐藏商品 ID、佣金、成交和未展示事实保持未知。

## 0.4.3

- 修复抖音单作品详情弹层中 `xgplayer-shop-anchor` 商品控件为可点击 `DIV`、没有链接标签时漏识别的问题；
- 小黄车发现只依赖播放器商品控件结构，不扫描或匹配视频文案、字幕、话题和普通文字；
- 同一轮播存在前后商品控件时，只接受当前进入视口且位于最上层的一条，屏幕外控件不进入结果；
- 控件只有展示名、页面没有直接 HTTP(S) 链接时，清理“购物｜”前缀并保存为 `visible_name_only`，不点击补链、不进入商品详情；
- 其余下载、评论、达人快照、批量顺序及交付边界保持不变。

## 0.4.2

- 明确单作品任务新增当前详情页可见小黄车观察，保存展示名、页面直接 HTTP(S) 链接、观察时间与明确状态；
- 观察结果同步进入 `works.json`、发布文案 TXT、`01_作品清单.xlsx` 的“可见小黄车”工作表与 `04_采集说明.md`；
- `not_observed` 只表示本次页面可见范围未发现，`visible_name_only` 表示页面可见但未直接提供链接，均不得扩写为商品或交易事实；
- 不点击商品、不进入详情，不补取或推断价格、店铺、销量、佣金、隐藏商品 ID、商品匹配或销售归因；
- 不改变主页、搜索、批量顺序、直播识别及评论采集合同。

## 0.4.1

- 单作品 `01_作品清单.xlsx` 新增“达人快照”，保存当前作品页已展示或加载的昵称、抖音号、稳定达人 ID、主页链接、简介、粉丝数、累计获赞、快照时间与来源作品；
- 未展示字段保持空白，明确显示 0 才写数字 `0`；
- 不自动进入达人主页补齐字段，不下载头像，不改变主页、搜索、插件选择和多作品批量合同；
- 增加作者字段规范化、零值与空值、单作品工作表和无头像边界的合成回归测试。

## 验收边界

- 自动化测试只使用合成数据；本版本未把插件真实页面验收等同于独立 Skill 的真实页面验收；
- 下载和快照只保留来源事实，不自动生成达人画像、粉丝质量、商品匹配或商业结论。
