# BrandBAI Douyin Download 0.6.3

## 0.6.3（字幕稳定修复试用包）

- 字幕包装接入随包 PP-OCRv5-mobile 本地模型及共用浏览器端引擎，不另写一套 Python 识别或文字改写规则。具体模型版本以 `assets/subtitles/vendor/manifest.json` 及结果中的 `runtime` 为准。
- `字幕识别记录.json` 和任务汇总记录实际引擎名称、版本依据、模型／字典及代码 SHA-256；执行前校验随包资源，运行结束再次核对。拒绝引擎声明与模型清单不一致的组合，运行期间组件变化不标记为已确认版本。
- 修复本地页面未声明 UTF-8 时，浏览器可能把脚本内中文处理规则按其他编码解释的问题；HTML 与脚本响应明确编码，识别前检查页面字符集和中文规则，失败即停止，不带着乱码规则继续处理。
- 明确单作品 `all --subtitles --subtitle-region` 在下载后直接读取作品记录绑定的本地视频；保留原有授权、作品身份、输出不覆盖与失败部分交付边界。普通下载不默认运行字幕。
- 保留原始逐帧观察与连续重复整理、采样时间段导出，不按商品词表改字，不把模型置信分数称为准确率。
- 新增可恢复的低可信首尾增字整理：只有同一连续区间存在可靠原图完整句、额外首尾字置信度极低且不涉及受保护表达时，才采用实际识别过的代表句；原始候选和原分段保留在 JSON，不能当作人工纠错或普遍无错保证。
- 仍需已核对的固定单行字幕区域；不含自动定位、在线播放器逐帧读取、跨进程字幕续跑或逐句配图。字幕处理完毕不代表整片无漏字、无错字。
- 本版作为试用包交付。真实本地视频流程验证不等于整片文字准确率通过，也不等于当前在线平台采集已验收；繁简字形、复杂背景和部分标点仍可能需要核对。

## 0.6.0

- 新增显式 `--product-reviews`：对一个明确挂车作品，按顺序保存作品、关联商品公开资料与当前商品评价；商品评价与作品评论独立保存。
- 商品评价模块基于 BrandBAI Chrome 插件 v0.11.156，支持当前评价容器自动滚动、进度记录、逐批落盘后确认、暂停及身份核验后的去重续跑；不需要安装浏览器扩展。
- 默认限额 200 条、200 次滚动、600 秒；预算停止、未识别条目及身份变化保持部分结果，不把页面评价总数当成已保存数。
- 新增普通交付 `05_商品评价.xlsx` 及独立原始数据、状态文件。未知商品 ID 不允许跨页面实例强行续跑合并；临时签名评价图片链接不进入导出。
- 修复已有商品弹层可错绑作品、规格／物流字段可混入个性化收货信息，以及非图片响应或已有损坏文件可误报成功的问题。
- 同步单 Skill 发布包、安装入口、使用说明与合成回归；没有把离线通过或插件截图表述为本 Skill 真实平台端到端验收。
- 商品视频文件、全 SKU 成交矩阵、逐 SKU 主图和商品评价媒体 ZIP 仍不在支持范围内。

## 验收边界

- 自动化测试只使用合成数据；本版本未把插件真实页面验收等同于独立 Skill 的真实页面验收；
- 下载和快照只保留来源事实，不自动生成达人画像、粉丝质量、商品匹配或商业结论。
