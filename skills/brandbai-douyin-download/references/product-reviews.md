# 挂车作品、商品资料与商品评价

适用版本：`brandbai-douyin-download v0.6.0`。这是用户明确选择的附加采集路线，不改变默认作品下载，也不自动进行分析或购买操作。

## 三类资料分别保存

- 作品：视频或图文、封面、可用原声、发布文案、基础数据；作品一级评论仍由原评论路线独立处理。
- 商品：从这条作品当前唯一的小黄车入口打开商品面板，读取已公开展示的标题、店铺、价格／销量快照、规格、参数、服务承诺与可用商品图片。
- 商品评价：只滚动该商品当前评价列表，保存本次可可靠识别的评价；不与作品评论混合，不承诺页面标注总数或全部历史评价。

同一次任务按顺序执行这些阶段，不代表后台同时浏览多个页面。商品读取时暂停作品，避免自动连播造成错绑。不会下单、修改地址或切换 SKU 来枚举组合。

## 请求与参数

仅限一个明确作品链接。以下示例先只做计划核对；确认后移除 `--dry-run`：

```bash
python scripts/run_foundation.py all --video "https://www.douyin.com/video/<作品ID>" --product-reviews --max-product-reviews 200 --product-review-max-scrolls 200 --product-review-max-seconds 600 --skip-comments --profile-dir "<私有浏览器目录>" --out "<输出目录>" --zip --dry-run
```

- `--commerce-detail`：只增加关联商品资料。
- `--product-reviews`：增加商品评价，并隐含商品资料阶段；用户未要求商品评价时不得自动增加此选项。
- `--max-product-reviews`：保存总数上限，默认 200，范围 1–2000；不是“全部评价”开关。
- `--product-review-max-scrolls`：单轮滚动预算，默认及最大 200。
- `--product-review-max-seconds`：单轮时间预算，默认及最大 600 秒。
- `--skip-comments`：只跳过作品评论，不跳过明确请求的商品评价。
- `--privacy-mode hash`：默认保存评价者稳定化名；原始名称模式需要用户明确授权。
- `--resume`：校验原任务范围、商品身份、筛选和隐私设置后续跑；不得据此跳过不完整的商品阶段。

首次需本人在可见 Chrome 中完成登录或验证码。验证码、访问限制和平台警告是停止条件，不通过变更指纹、代理、账号或请求方式重试绕过。

## 页面与身份核对

1. 冻结作品 ID，暂停播放，确认当前作品只有一个可定位的商品入口。
2. 如果页面预先打开了来源不明的商品面板，停止并要求关闭后重新从目标作品进入，不能把现有商品直接归给该作品。
3. 新商品面板稳定后才读取；评价阶段继续检查作品、商品、面板实例、评价区域和筛选。
4. 未获得公开商品 ID 时保留未知，不把作品 ID 或名称推断成商品 ID。
5. 页面隐藏、作品或商品切换、筛选变化、区域无法可靠识别时停止。短暂无新增不等于完成；只有已确认的当前列表结束信号才可标为完成。

商品资料不读取收件人、手机号或个性化收货地址。商品图片仅接受允许的公开商品图片域名和实际图片文件签名；非图片响应保持失败，不伪装为 JPG。

## 进度、暂停与续跑

商品评价采集逐批持久化，再向页面确认该批结果。进度包括已保存数、页面已加载数、解析数、未识别数、阶段、滚动次数和用时；宿主可读取 `data/商品评价/product_review_manifest.json` 展示动态状态。这是 Skill 的文件进度接口，不是浏览器扩展右侧界面。

需要暂停时，在运行中的商品评价目录写入 `product_review_control.json`，内容为 `{"action":"pause"}`；或者在前台按一次 Ctrl+C。等待原任务完成保存确认，不重复启动、不强杀浏览器。暂停文件不会自动变成继续指令；明确续跑前将其更新为 `{"action":"continue"}`，并确认原进程已退出。

只有身份核对通过的原任务才可续跑。缺少公开商品 ID 时，只允许同一仍存活的页面、商品面板和筛选实例续跑；刷新、关闭或重建页面后的未知身份不能强行合并。此时保留旧结果，核对后使用新输出目录。命令行重新启动通常会建立新页面，因此不保证无商品 ID 的跨命令续跑。

暂停、风险或身份异常后不得为了下一阶段自动跳走。达到用户设置的采样预算也仍是部分结果。恢复前先检查当前状态，而不是无限点击继续。

## 文件与完成状态

- 普通交付中的 `05_商品评价.xlsx`：独立评价表，文本、昵称化名、日期、所购规格、可见有用数、追评与图片引用等以实际可得为准；文本按文字写入，不执行公式。
- `data/商品评价/商品评价.xlsx`：商品评价阶段工作表。
- `data/商品评价/product_reviews.jsonl`：去重后的结构化评价。
- `data/商品评价/product_review_manifest.json`：身份范围、筛选、计数、进度和停止原因。

不下载商品评价图片／视频 ZIP；只保留安全的公开图片引用和数量，临时签名链接不进入导出。商品视频文件、完整 SKU 成交矩阵、每个 SKU 图片遍历、隐藏商品信息也不在本版承诺内。

完成只表示已确认当前公开列表的结束，不代表平台绝对全量。预算停止、用户暂停、没有明确结束信号、未可靠识别的条目和浏览器异常都保留部分结果；统一流程以退出码 `3` 表示需要关注的部分交付，不把已有作品素材丢弃。

## 本版验证边界

评价解析与滚动逻辑基于 BrandBAI Chrome 插件 v0.11.156 的商品评价模块，适配为随 Skill 一起分发的本地代码；不依赖用户安装该扩展。

本版使用离线合成页面和数据回归检查绑定、保存确认、暂停、预算、续跑、隐私与交付。插件既往页面截图不等同于本 Skill 的真实平台端到端验收；网站结构变化、登录状态及平台限制仍可能导致部分结果。
