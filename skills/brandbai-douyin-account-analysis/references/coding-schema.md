# 评论与证据编码

## 主语义

进入分布计算的每条评论只设置一个主语义：

| 代码 | 主语义 | 说明 |
|---|---|---|
| C | 内容／方法 | 观点、步骤、动作或知识 |
| P | 人物／状态 | 外貌、年龄、性格或状态 |
| R | 关系／记忆 | 搭档、旧角色、作品或公众记忆 |
| V | 场景／意外细节 | 服装、道具、地点、造型或画面梗 |
| B | 品牌／商品 | 品牌、产品、价格、规格或使用 |
| E | 自身经验 | 自己的问题、经历或反向经验 |
| A | 活动／噪声 | 抽奖、口令、直播、互关、纯表情或复制内容 |

## 辅助标签

可以多选：复述观点、跟练收藏、具体提问、经验补充、商品兴趣、自报购买、质疑、人物赞美、关系联想、无关争议。

## 接收深度

| 层级 | 用户表现 |
|---|---|
| S0 | 无有效信息 |
| S1 | 注意人物、场景或细节 |
| S2 | 理解并复述内容 |
| S3 | 映射到自身问题或经验 |
| S4 | 收藏、跟做或继续提问 |
| S5 | 进入品牌、商品、价格或购买信息 |
| S6 | 自报购买或使用，仍需外部验证 |

S0—S6 不是购买漏斗。S5、S6不能证明点击、加购或成交。

## 对齐等级

- 高对齐：评论反复复述核心内容，并出现相应问题或行动。
- 部分对齐：核心内容被接收，但人物、关系或商品共同分流。
- 分裂对齐：兴趣与质疑、赞同与反驳同时成为明显中心。
- 低对齐：评论主要讨论与视频任务无关的内容。
- 未知：评论不足、无法匹配或完整性过低。

## 证据状态

- F：可观察事实。
- P：多个可比样本重复，并检查反例后的模式。
- H：有线索但仍需验证的假设。
- U：未知、未采集或无法对齐。

## 最低证据字段

```text
evidence_id
video_id
source_role
comment_text
digg_count
reply_count
comment_time
parent_id
source_file
source_row
completeness
main_semantic
auxiliary_tags
reception_depth
```

一级评论、观众回复和达人回复分开。页面兜底 ID 的证据强度低于平台评论 ID。评论文字存在是 F；评论中的身份、体验、购买和效果主张仍需核验。
