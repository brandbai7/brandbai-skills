# 浏览器路线

## 稳定路线

1. 使用可见 Google Chrome 和独立持久资料夹；首次登录与验证由用户完成。
2. 每次任务只启动一个浏览器上下文，多个明确商品链接在同一标签页顺序处理。
3. `product` 只读取商品页公开 DOM 与允许的媒体 CDN，不依赖评价或问答面板。
4. `reviews` 先定位并高亮“查看全部评价”，由用户点击后滚动完整评价容器；未打开时返回部分状态。
5. `questions` 先定位并高亮“查看全部问答”，由用户点击后展开可见回答并滚动问答容器；未打开时返回部分状态。
6. manifest 只保留去掉敏感查询参数后的公开 URL，任务结束后不删除私有资料夹。

## 禁止事项

- 不读取或复制 Cookie、Local Storage、请求头、密码、验证码和资料夹内容。
- 不自行生成平台签名，不重放隐藏接口，不绕过滑块或访问控制。
- 不把账户昵称、购物车、收货地、地址或个性化推荐写入商品包。
- 不把 DataTool 或其他扩展注入的按钮、图标和脚本当作商品内容。
- 不把商品首页露出的少量评价／问答卡片描述为全部。

页面定位失败时记录部分状态并保留已有数据；不要静默返回空表或把空白解释为 0。
