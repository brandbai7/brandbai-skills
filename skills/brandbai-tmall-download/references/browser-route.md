# 浏览器路线

## 稳定路线

1. 使用可见 Google Chrome 和独立持久资料夹。
2. 用户首次手动登录天猫；程序只复用正常页面会话。
3. 每次任务只启动一个浏览器上下文，多个商品在同一标签页顺序处理。
4. 商品资料先读页面可见 DOM；评价打开“查看全部评价”后滚动评价容器。
5. 媒体只从允许的天猫／淘宝 CDN 主机即时下载；manifest 只保留去掉查询参数后的公开 URL。
6. 任务完成后关闭本次自动化上下文，不删除私有资料夹。

## 宿主适配

- 宿主能运行本地 Python：直接调用 `scripts/run_foundation.py`。
- 宿主能控制用户已登录 Chrome 但不能运行本地脚本：可按同一采集合同导出结构化文件，但必须保留状态字段；不要声称已使用本脚本。
- 宿主既没有本地终端也不能控制浏览器：只能生成 dry run 与环境检查，不能假装完成采集。

## 禁止事项

- 不读取或复制浏览器 Cookie、Local Storage、请求头、密码、验证码和资料夹内容。
- 不自行生成平台签名，不重放隐藏接口，不绕过滑块或访问控制。
- 不把账户昵称、购物车、收货地、地址或个性化推荐写入商品包。
- 不把 DataTool 或其他扩展注入的按钮、图标和脚本当作天猫商品内容。

## 页面变化

优先使用语义文本和结构特征，CSS 哈希类名只作为兜底。定位失败时记录 `partial_selector_drift` 并保留已经写入的数据；不要静默返回空表或把空白解释为 0。
