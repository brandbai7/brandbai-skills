## 0.1.0 首发记录

这是 BrandBAI 商品侧第一个公开采集 Skill，负责把明确天猫／淘宝商品链接转换为可回溯的商品资料、素材、SKU 快照与页面可见评价。

### 首发能力

- 支持一个或多个明确商品链接顺序采集；
- 支持商品标题、店铺、页面参数、SKU 可见选项与选中 SKU ID；
- 将价格、销量、库存等易变化字段独立记录为带时间的页面快照；
- 支持主图、详情图、页面可见商品视频和可选评价媒体；
- 支持评价面板滚动追加、评价与追评区分、稳定去重和断点续跑；
- 默认对评价者使用稳定化名；
- 生成 `01_商品资料.xlsx`、`02_评价明细.xlsx`、商品素材、采集说明和可选 ZIP。

### 完整性边界

- 页面提示折叠评价时固定标记 `partial_platform_folded`，即使已滚到当前可见源末端也不称平台绝对全量；
- 达到用户设置的评价上限时标记 `partial_limit_sample`；
- 价格、销量、库存、促销和 SKU 状态只是采集时点快照；
- 登录、验证码和访问确认由用户手动完成；
- 不导出 Cookie、请求头、浏览器资料夹、账号信息、收货地区或签名材料；
- 下载阶段不自动生成商品价值、卖点、用户语义或商业结论。

### 验证

- URL 去跟踪、媒体白名单、隐私化名、完成状态、Excel、ZIP 和 dry run 均使用合成数据测试；
- 已在正常登录的天猫商品页验证商品标题、规格参数、SKU 选项、媒体结构、评价卡片和评价滚动追加结构；
- 首发版本以明确商品链接列表为稳定输入，不自动抓取全店或搜索结果集合。
