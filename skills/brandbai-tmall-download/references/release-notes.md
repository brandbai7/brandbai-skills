# BrandBAI Tmall Download 0.3.2

## 0.3.2

- 根据英氏真实商品包修复小数价格与活动月份粘连：`优惠前￥66.88月19日` 识别为66.8元；正常分隔的小数价格不误删；
- 将店铺会员、会员尊享与尊享特权等页面动作从SKU可见选项排除；
- 完整继承0.3.1的价格角色、当前规格／页面参数分层、素材双序号和内容／经营两层状态。

## 0.3.1

- 修复100、79、399等价格与活动月份紧贴时的截位，并避免父级价格文本重复串联造成角色错配；
- 当前选中规格与页面通用参数分开，普通按钮不再进入 SKU 选项；明确身份冲突只提示人工确认；
- 素材索引同时保存页面原序和下载序，详情图增加有效内容、低信息候选与质量排除状态；
- 商品内容资料状态与经营快照状态分开；可选视频未展示仍不算失败；
- 修复 Windows 中文路径下 Python 3.14 临时目录兼容，合成测试不再因 ACL 假失败。

## 0.3.0

## 本次升级

- 商品参数、主图、图文详情和视频改为四个独立读取模块，逐项完成后再合并商品包；
- 图文详情只在模块边界内有限前进以触发懒加载，动态在推荐区前停止，并在成功或异常后恢复进入前的位置；取消商品资料路径里的整页滚动；
- 可信淘宝图片 CDN 的旧 `http://` 素材在白名单校验后按 HTTPS 请求，避免同一详情页只保存前几张 HTTPS 图片；
- 单个模块定位或下载失败时保留其他模块成果，并在 `module_states`／`module_failures` 中记录；
- 推荐区继续被排除，但现在通过模块根节点隔离，而不是依赖滚动停止位置；
- 与浏览器下载助手 v0.10.0 对齐模块合同和合成回归。
- 修复价格与活动日期紧贴时把月份误拼进原价的问题，并把“店铺优惠后”识别为促销价语境；真实四位数价格在没有日期边界时仍完整保留。
- 增加“补贴后”促销价语境；独立的百亿补贴金额仍作为优惠权益，不与商品价格混写。
- 增加 SKU 五态映射合同；页面只有 SKU ID、没有可见选中规格时降级为 `partial_product_identity`。
- `01_商品资料.xlsx` 新增逐条结构化“价格与权益”工作表，并在商品总览输出 SKU 映射状态与价格识别状态。
- 商品 JSON 与总览新增详情加载步数和原位置恢复状态，便于审计模块边界。

## 0.2.3

- 详情素材加载改为单向前进，不再先定位后回拉，也不会在动态高度变化时重复向上滚动；
- “看了又看／猜你喜欢”等推荐区继续作为硬停止边界，详情未真正读到图片时不再标记完整；
- 店铺名不再强依赖链接节点，仍限制在当前商品上半屏并排除推荐区；
- 扩展商品视频探测到播放器、DOM 属性与页面内嵌配置，并保留“有播放器但无可下载源”的未知状态；
- 与浏览器下载助手 v0.9.6 对齐真实页质量状态和合成回归。

## 0.2.2

- 详情素材滚动改为以图文详情为边界，在“看了又看／猜你喜欢”等推荐区前停止，不再加载无关推荐商品；
- 收紧店铺、价格、销量与经营信息范围，推荐商品不能再冒充当前商品事实；
- 补充天猫主图播放器临时视频地址的即时下载路径，签名参数不写入交付物；
- 排除六个真实商品共同出现的平台“价格说明”图片，不再把它计为商品详情内容；
- 详情短条阈值与插件统一为 80px，并新增推荐区、视频和平台说明图回归。

## 0.2.0

## 本次升级

- 将商品资料、评价和问大家拆成三项独立能力，商品资料包不再被评价或问答长列表阻塞；
- 新增 `questions` 模式，保存问题、页面可见回答、稳定或兜底 ID、匿名作者和独立完成状态；
- 评价和问大家都会先定位并高亮“查看全部”入口，等待用户手动打开完整面板；未打开时明确标记部分完成；
- 新增 `03_问大家.xlsx`，并且没有请求的数据集不再生成空工作簿；
- 保留价格、促销、销量、库存、SKU 快照、平台折叠和页面展示量差异等证据边界；
- 新增商品／评价／问大家三类数据的合成回归测试。
