# 采集完成标准

## 商品

每个商品至少保留：

- 稳定 `item_id` 与 `product_id=tmall:<item_id>`
- 去跟踪参数的 canonical URL
- 商品标题和采集时间
- 页面可见参数、SKU 选项与选中 SKU ID
- 价格、销量、库存等时点快照
- 每个所选媒体的下载或不可用状态

商品媒体失败时使用 `partial_asset_failure`，不能仅因标题成功就标完整。

## 评价

每条记录至少包含：

- 平台评价 ID 或明确标注的 `derived:` 兜底 ID
- 商品 ID、内容角色、评价时间原文、购买规格原文、评价原文
- 稳定化名；页面遮罩名默认不保留
- 采集时间与媒体索引

评价完成状态优先级：

1. 登录／验证阻断
2. 页面定位变化
3. 用户样本上限
4. 平台折叠提示
5. 当前可见源末端
6. 未到末端

所以滚动到末端但页面显示折叠评价时，仍是 `partial_platform_folded`。

## 数量口径

- `saved_reviews` 统计实际写入并去重后的评价、追评等内容记录。
- 页面显示的“5000+”是展示量，不等于精确记录数。
- 平台折叠数量单独记录，不与已保存量相加后冒充全量。
- 空白、未知、未观察到和确认的 0 必须分开。

## 退出码

- `0`：请求范围按本合同完整完成。
- `3`：结果可保留、可交付为部分数据并可续跑。
- `2`：输入、环境或执行失败，需要处理后重试。
