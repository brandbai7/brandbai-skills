# 普通版导出格式

## 目录

```text
BrandBAI_天猫商品资料_<商品或项目名>_<日期>/
├─ 01_商品资料.xlsx
├─ 02_评价明细.xlsx
├─ 03_商品素材/
│  └─ <商品标题>/
│     ├─ 主图/
│     ├─ 详情图/
│     └─ 视频/
├─ 04_采集说明.md
└─ data/
   ├─ run_manifest.json
   ├─ delivery_manifest.json
   ├─ 商品采集/<item_id>/
   │  ├─ product.json
   │  └─ asset_manifest.json
   └─ 评价采集/<item_id>/
      ├─ reviews.jsonl
      └─ review_manifest.json
```

## `01_商品资料.xlsx`

- `商品总览`：商品 ID、标题、店铺、链接、选中 SKU、价格／销量／库存快照、时间和状态。
- `规格参数`：参数名、参数值、来源链接和时间。
- `SKU快照`：规格组、顺序、页面可见选项和当时选中的 SKU ID。
- `素材索引`：素材 ID、类型、顺序、文件、公开来源 URL、查询参数脱敏状态和下载状态。
- `完整性`：商品资料与评价分别写状态和数量说明。

## `02_评价明细.xlsx`

- `评价明细`：评价 ID、ID 类型、商品 ID、内容角色、匿名 ID、评价时间原文、购买规格原文、评价原文和媒体数量。
- `采集状态`：每个商品的保存量、折叠提示数、是否到末端、样本上限、隐私模式和完成时间。

## 后续 Skill 接口

商品价值 Skill 优先读取 `product_id`、`item_id`、parameter 表、SKU 快照、素材索引和评价原文。后续分析可以增加自己的标签和结论，但不得改写下载包中的来源字段；修正只能新增更正记录并保留原值。
