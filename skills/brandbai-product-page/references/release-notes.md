# BrandBAI Product Page 0.5.1

当前状态：本地候选版。

- 修复普通中文比例、规格与包装表达中的斜杠被误判为本地绝对路径，例如 `55%/33%`、`抽数/包数` 与 `500ml/瓶`；
- `recommendation_label` 成为每条改版项目的必填字段，只允许四种正式建议标签，空白与自造标签会被校验器拒绝；
- MP4、MOV、M4V、WEBM、AVI 与 MKV 页面素材统一识别为 `video`，不再混入 `other`；
- 三份普通版使用“品牌内部商品资料／已验证卖点资产／补充资料与人工确认”等品牌语言，不再暴露“商品价值上游／卖点呈现上游／返回上游”等内部流程词。

## 0.5.0

当前状态：本地候选版。

- 报告合同从“逐图找问题”升级为“页面整体诊断—整体重构策略—改版项目—逐模块执行”；
- 先说明当前成交策略、核心购买理由和已经做对的部分，再收敛为最多三个整体根因；
- 新版购买逻辑必须形成连续叙事路线，并明确主图、交易区、详情页和决策收口的职责；
- 除“保留”外，每个改版项目必须绑定至少一个整体根因，不能从单张图直接生成零散建议；
- 普通报告不再披露页面材料的采集与选择过程，只讨论页面主讲 SKU、当前可见交易选项和证据适用性；
- 保留五个购买判断与证据相关性规则：包装克重、罐数或版式差异不自动使检测结论失效。

## 0.4.3

当前状态：公开候选版。

- 五决策从状态标签升级为四段式诊断：已讲清、还没讲清、购买影响和具体补法；
- 优先动作只能针对未讲清部分，已经讲清的判断不再重复给建议；
- 检测报告与当前SKU存在克重、罐数或包装差异时，改为判断差异与检测结论的相关性，不再自动判定证据无效；
- 只有配方、原料、产品形态、型号、适用对象、生产主体或被检测项目存在实质差异时，才按证据错位处理。

## 0.4.2

- 新增“页面主讲SKU”分析对象闸门：只要页面主讲SKU可被识别且在可见购买选项中唯一匹配，就以该SKU继续分析；
- 价格、赠品、库存、物流和实际到手快照必须明确归属于分析SKU，不得跨SKU沿用；
- 页面主讲SKU不可购买、无法唯一匹配或页面不存在主讲对象时，必须暂停并要求人工确认；
- 普通诊断报告新增品牌决策首页：先说明分析SKU、最影响购买的三件事与明天第一步，再呈现完整五决策、动作和证据底稿；
- 五决策改写为消费者能直接理解的五个购买问题，页面页纲增加改版顺序总览。

## 0.4.1

- 修复专业版页面页纲暴露内部成交角色枚举的问题，统一输出“正装主销”等客户可读中文标签；
- 增加客户报告不得出现 `standard` 内部枚举的回归检查。

## 0.4.0 基础能力

- 对外名称统一为“BrandBAI 商品页诊断优化”；
- 从“强制继承商品价值与卖点呈现”改为一个可独立运行的商品页 Skill；
- 新增 `diagnose_existing` 与 `enhance_with_evidence` 两种输入模式；
- 现有页面即可完成一核、五决策、SKU、页面顺序、证据错位与零至五项动作诊断；
- 包装、参数、检测、用户信号、业务资料与竞品页面可作为可选增强输入；
- 商品价值与卖点呈现交付仍可继承，但不再是启动条件；
- 普通专业交付改为诊断建议、页面页纲、资料缺口与证据边界三份 Markdown；
- Excel 页纲改为宿主有表格能力时的可选同源导出，Markdown 保持跨模型必交；
- 延续 50 个高销商品页候选版中已经验证过的交易角色、SKU／套组、变体、量化主张、高风险品类、实际到手和跨页面一致性检查。

高销样本只支持方法覆盖与边界，不证明页面结构导致销量，也不构成品牌排名、固定爆款模板或转化保证。
