# 交付合同

## 1. 普通入口

### 01_商品页诊断与优化建议.md

固定包含：

1. 本次商品、当前 SKU／套组、页面范围、页面时间和可读范围；
2. 页面当前核心购买理由及其证据等级；
3. 认对、看懂、相信、选对、放心买五个判断；
4. 零至五项优先动作及四类建议标签；
5. 第一项开工动作、本轮暂不做和结果边界。

### 02_主图交易区详情页优化页纲.md

按实际页面顺序列出：区域／张序、当前任务、建议任务、主要决策、动作、建议表达、所需素材、必须保留、禁用表达、负责人和验收问题。

它是静态页面执行页纲，不是最终设计稿或整套成品文案。页面不需要的模块不得为了模板完整而补齐。

### 03_资料缺口与证据边界.md

分为：可直接调用资料、补充后可调用资料、动态快照、待人工核实、禁止扩写、后续可选资料。必须明确“当前资料能证明什么／不能证明什么”。

课程模式可只输出 `01`；专业模式固定输出三份。

## 2. 动作标签

每项动作只使用一个主标签：

| 标签 | 允许进入页纲 | 含义 |
| --- | --- | --- |
| 可直接优化 | 是 | 不新增资料外主张，可立即调整结构、顺序或已确认表达 |
| 补充资料后优化 | 条件式 | 先补事实、证据、素材或授权，再进入正式改版 |
| 待上线验证 | 是 | 可执行但效果未知，写明上线观察问题 |
| 不建议使用 | 否 | 证据越界、跨SKU、过期、误导或无法兑现 |

动作类型仍只使用：`保留／删除／补充／前移／重新组织／人工核实`。

## 3. 正式交付门槛

- 只处理一个当前成交单元和一个页面版本；
- 至少一份页面材料已视觉读取，否则停止且零动作；
- 当前 SKU 不明时，不输出会改变卖点或证据的正式动作；
- 非停止状态固定完成五个购买判断，不生成总分；
- 页面当前主张与已确认事实分开；
- 增强资料逐项记录适用 SKU、能证明和不能证明；
- 页面动作总数不超过五项，依据不足可以为零；
- 每项动作绑定页面位置和可读来源；
- 页面已有结构调整可以只用页面可见依据，新主张必须调用可用补充证据；
- 评论只作为用户信号，竞品只作为结构／表达观察；
- 动态权益有时间，过期或时间未知时只进入人工核实；
- 其他变体、套组单品、关联商品和品牌共性不证明当前 SKU；
- 普通版无内部 ID、本地绝对路径、技术字段或模板占位符；
- 三份普通文件使用同一底稿，不出现事实、优先级和边界漂移；
- 所有动作均不承诺点击、转化、GMV、ROI 或销量提升；
- 校验退出码为零。

正式通过只表示本次静态诊断、证据和交付结构完整，不表示页面已经有效、视觉稿已发布或改版产生经营结果。
