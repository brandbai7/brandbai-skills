# 交付合同

## 1. 课程模式

只输出 `01_商品页与主图优先优化行动单.md`。面向普通品牌学员，15—30分钟内可以读完并开始执行。

固定包含：

1. 本次对象、SKU、范围、页面时间和可读范围；
2. “认对、看懂、相信、选对、放心买”五个判断；
3. 零至五项优先动作；降级模式最多三项；
4. 返回商品价值、卖点呈现或页面资料的缺口；
5. 第一项开工动作、本轮暂不做和限制说明。

每项动作必须让学员看懂：页面哪里、当前问题、为什么改、具体改什么、保留什么、还要补什么、怎样检查。课程版隐藏内部 ID、Schema、路径和代码状态。

## 2. 专业模式

普通入口只有：

```text
01_商品页判断与优先修复.md
02_主图与详情页下一步.md
```

`01` 保留页面对象、证据成熟度、五个用户判断、跨触点一致性、最多五项动作、冲突和限制；`task=route` 时额外白话显示“页面共用与分版建议”。

`02` 按主图张序或详情模块顺序说明当前功能、建议功能、动作、执行要求、所需素材、验收问题和版本验证。可以优化时它是执行 Brief；降级或停止时明确写“本轮不改图”或“暂停页面动作”，只保留核验与补资料方向。它不是最终视觉稿或完整成品文案。

完整来源、组件、判断、动作、验证和缺口留在 `data/`，用于审计和下游交接。

## 3. 正式交付门槛

- 只处理一个 SKU 和一个当前页面版本；
- 页面来源、文件哈希、真实位置、顺序和可读状态可回溯；
- 页面决策链锁定当前交易角色、监管身份和当前SKU；真实SKU与说明／服务／关联商品入口分开；
- 适用对象、变体证据、量化主张、展示与实际到手及升级对照保留边界；
- 至少一份本次范围内页面可读，否则停止且零动作；
- 非停止状态固定完成五个用户判断，不生成总分；
- ready/partial 的正式动作全部引用页面来源和有效商品价值；
- ready/partial 的动作继续遵守上游 `cannot_prove` / `misuse`，不得把已限制主张重新启用为执行卖点；
- 每个非“资料不足”的用户判断都绑定可读页面与组件；“资料不足”必须保留明确未知；
- degraded 动作不超过三项且不调用上游价值；
- blocked/stale 的组件、动作、路由或验证任务不得进入正式普通稿；
- 所有模式优先动作总数不超过五项；
- combined 有跨触点一致性判断，不是两份报告拼接；
- 重要不可读、未提供、冲突和动态待确认全部保留；
- 评论未进入商品事实，P0/P1/P2未被改写；
- 所有动作标为待验证建议，没有点击、转化、GMV或ROI承诺；
- 课程版无内部 ID、绝对路径和技术字段；
- 专业版与课程版使用同一判断底稿，不出现事实和优先级漂移；
- version_review 只接受 `current` 与 `comparison` 两个真实版本，时间带时区、两版有共同可读范围，验证任务绑定真实版本；
- route 有独立结构化判断，绑定入口语境、页面来源、组件和商品事实/价值；
- 报告没有模板占位符，校验退出码为零。

正式通过表示交付结构、证据和边界完整，不表示页面有效、视觉稿已完成或改版能提升经营结果。
