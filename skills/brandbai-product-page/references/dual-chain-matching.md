# 双链匹配方法

商品页诊断以两条链的匹配为核心，不从通用页面模板直接生成建议。

## 1. 两条链分别是什么

### 细分类目用户购买决策链

回答“用户购买这一细分类目、这个商品形态和当前 SKU 时，需要依次确认什么”。它不是固定行业模板，必须结合当前商品、页面角色、适用对象、使用任务、规格结构与风险等级生成。

每个任务记录：顺序、用户问题、必答或条件必答、重要性、形成依据、来源与边界。

成熟度只使用：

- `working_hypothesis`：仅依据当前页面、商品形态与本参考形成的工作假设；
- `evidence_strengthened`：又有商品资料、客服／评论样本或竞品结构观察支持；
- `brand_confirmed`：经品牌业务负责人确认；
- `user_validated`：有可回溯用户研究或行为验证支持。

只读当前页面时，不得把类目链写成“消费者普遍如此”。

### 页面内容信息链

由 `page_component_ledger.jsonl` 与 `ordered_component_ids` 共同构成，回答“主图、交易区和详情页现在按什么顺序讲了什么”。每个内容节点必须关联至少一个细分类目决策任务；无法关联的内容应被判断为干扰、重复或资料不足，而不是默认有价值。

页面当前路线只能从已经观察到的内容节点生成。`rebuild_strategy` 中的建议购买顺序属于未来方案，不能写成“页面当前实际在讲”。

## 2. 怎样匹配

`content_decision_match_ledger.jsonl` 对每个细分类目任务固定形成一条匹配记录，分别判断：

1. **有没有承接**：已承接、承接较弱、缺失、冲突或未知；
2. **出现位置是否合适**：位置合适、过早、过晚、分散、未出现或未知；
3. **证据是否接得上**：连接清楚、较弱、断裂、不需要证据或未知；
4. **信息量是否合适**：聚焦、必要重复、重复、过载、不适用或未知。

匹配不是简单“有／没有”。内容已经出现但太晚、与证据分离、跨 SKU、重复过多或与用户任务冲突，仍属于真实断点。

## 3. 怎样生成改版项目

先找双链断点，再收敛为整体根因和零至五个改版项目：

```text
细分类目购买任务
→ 页面当前内容节点
→ 缺失／承接弱／顺序错位／证据断裂／重复过载／冲突
→ 用户犹豫或误选后果
→ 改版项目
```

每个非“保留”项目必须关联至少一个仍有断点的细分类目任务。已经完全匹配、位置合适、证据连接清楚且没有重复问题的任务，只进入保留，不得为了凑动作再次改造。

### 详情页已有优势与提升空间

双链匹配不只用于找问题，也用于识别品牌已经积累的成熟资产：

- **已有优势**：某项细分类目购买任务已有清楚内容承接，出现位置符合用户判断顺序，主张与证据连接明确，且没有明显重复或信息过载；同时它至少帮助认对、看懂、相信、选对、放心买中的一个判断。
- **还可提升**：某项任务虽然已有内容，但仍存在缺失、位置偏后、证据没有连到对应主张，或重复信息挤压主线；并且该断点会实际增加某个买前判断的理解或选择成本。
- **不进入评价**：单纯版式喜好、没有证据的审美判断、与购买无关的局部差异，以及为了让报告显得完整而凑出的优缺点。

优势只写“为什么值得保留、改版时怎样保护”；提升空间只写“哪里还没讲清、影响什么购买判断、怎样才算改善”。两者都必须回指详情页内容节点、细分类目任务和五个买前判断。

## 4. 与一核五决策的关系

- 细分类目购买决策链决定“应该讲什么、先讲什么”；
- 页面内容信息链还原“现在讲什么、按什么顺序讲”；
- 一核五决策负责跨品类验收“用户最终是否认对、看懂、相信、选对、放心买”。

五决策不能替代细分类目任务，细分类目任务也不能取消事实、SKU、证据和交易边界。

## 5. 品牌报告怎样呈现

复杂字段只留在 `data/`。普通报告只呈现：

- “用户下单前，需要依次确认”哪些问题，并用一句自然说明交代它来自页面、补充资料、品牌确认还是用户研究；
- 页面现在实际按什么顺序讲；
- 影响最大的零至三个关键问题，用“页面目前怎么讲＋不讲清会怎样”表达；
- 最影响下单的问题如何转成改版项目。

不得把匹配表、内部 ID、成熟度枚举或承接／位置／证据／重复四组校验状态逐字段摊给品牌。只读页面时不得写成“这类商品用户通常如此”，也不使用“本次先按这条购买顺序检查”等内部审查口吻；统一写成“用户下单前，需要依次确认”，并说明这份顺序是根据当前资料整理、仍可继续校准。

详情页不按旧图张序输出建议。诊断阶段仍需完整读取每张详情图并登记为内容节点；改版阶段把这些节点组织成少数连续内容章节，再用新版安排表说明旧内容继续使用、集中到一个章节、分别放入不同章节、调整顺序或本轮不使用。主图因为张数和位置固定，可以逐张安排任务；详情页必须按购买决策和信息章节组织。
