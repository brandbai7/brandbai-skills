# 快消品商品页判断参考

本参考用于辅助识别页面承担的用户决策任务，不提供固定模板，也不把任何行业页面顺序写成普遍规律。先完成当前 SKU、页面范围、商品价值与证据边界核对，再选择最接近的判断负担。

## 先定页面角色

- **单品价值页**：重点解释一个当前商品为什么值得买，价值、证据与当前SKU必须一致；
- **多SKU／套组选择页**：重点讲清版本、组合、选择顺序、套组构成和实际到手；
- **专属入口承接页**：重点接住达人、直播、活动或其他上游承诺；没有可靠入口资料时只能做静态页面判断；
- **任务混合或未知**：明确混合风险或资料未知，不强行套用某一种完整页模板。

品牌熟悉度只能降低部分品牌认知成本，不能替当前商品完成价值理解、当前SKU选择和实际到手确认。页面角色判断先于五决策权重判断。

## 五类常见判断负担

### 1. 高风险功效或安全类

常见于护肤、个护、母婴、营养与健康相关商品。页面通常需要连成：

```text
主张 → 为什么可能成立 → 页面拿什么支持 → 谁适用／怎么用／不能证明什么
```

不要只数检测图、专家图或专利图。每项机制、证据和体验结果都要绑定它正在支持的具体主张，并保留适用范围与风险边界。

### 2. 性能或体验可演示类

常见于纸品、清洁、洗护与母婴消耗品。页面可以检查：

```text
结构或配方 → 可见动作／对照演示 → 用户能感知的结果 → 使用条件
```

演示是待验证呈现，不自动等于普遍效果。视觉冲击不能替代商品事实和当前 SKU 适用性。

### 3. 多 SKU、多规格或组合装类

常见于食品、纸品、清洁、母婴与套装商品。页面首先要帮助用户分清：

```text
这是什么系列 → 当前选中的 SKU 是什么 → 与其他规格怎么选 → 实际收到什么
```

系列共用信息、其他 SKU 信息和当前 SKU 信息必须分开。混合发货、包装切换、赠品和活动组合都属于动态交易信息。

先抄录平台原始规格组，再规范化成用户选择维度。常见混合包括：

- 食品“口味”同时混入口味、数量、组合和包装版本；
- 美妆“颜色分类”同时混入配方、色号、限定版本和容量；
- 护肤套组“版本／颜色分类”同时混入产品代际、套组构成和赠品。

正式页面应按用户选择顺序组织，不应让用户自行解码平台的混合字段。

### 4. 新品类或行为替代类

常见于需要改变原有使用习惯的商品。页面可以检查：

```text
原来哪里不方便 → 为什么值得替换 → 怎么使用／处理 → 有什么边界或风险
```

问题教育不能无限放大焦虑；替代理由必须回到已确认商品价值，不能由页面话术反向制造核心价值。

### 5. 高频低决策类

常见于纸巾、零食、日常清洁等。页面通常更需要压缩判断成本：

```text
快速认出 → 一个主要价值 → 一个看得见的支持 → 规格／到手／价格权益
```

这不代表页面越短越好，而是每个模块要有明确任务，避免活动、品牌故事和重复卖点淹没当前 SKU。

## 跨品类都要检查的四层

1. **长期商品信息**：商品身份、价值、机制、稳定使用方式与长期边界。
2. **当前活动信息**：价格、赠品、会员权益、限时承诺与活动包装，只按页面时点成立。
3. **交易承接信息**：SKU、数量、组合、到手、物流、售后与使用选择。
4. **信任与合规信息**：检测、认证、研究、品牌或专业背书；必须说明它支持什么，不用“堆证据”代替判断。

## 使用限制

- 不以案例频次生成行业标准或固定页序。
- 不因为页面是销量高商品，就把页面结构与销量建立因果关系。
- 不复制第三方品牌文案、画面或专有设计。
- 不从活动素材推导长期定位，不从系列页面推导当前 SKU 事实。
- 经营数据缺失不影响静态页面判断，但也不能声称某项动作会提升结果。

## 50案例后的稳定检查项

- 当前成交单元不只是一串SKU，还包括试用、新客、正装、囤货、补充或礼赠角色；
- 色号、口味、段位、月龄、产品形态和包装版本都可能是商品身份的一部分；
- 规格区可能混入说明、会员服务、关联商品或占位项，不能全部当作可成交SKU；
- 医疗器械、婴配食品、婴幼儿辅食等高风险品类先确认产品身份和适用边界；
- 百分比、时长、倍数、温度、人数等量化表达要有对象、条件、时间、口径和可读来源；
- 展示成品、搭配道具和使用场景不自动等于包装实际包含；
- “新一代／升级”要说明旧版、新版、改变对象和可比证据；
- 页面长度不是质量指标，当前商品的购买决策是否闭合才是。
