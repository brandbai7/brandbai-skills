# BrandBAI Product Value 0.1.7

这是交付真实性、FABE 边界与候选完整性修订版：

- 双遍图片审计同时核对序号映射与时间递进关系，拦截事后批量生成的伪逆序复核记录；
- 含禁止食用、请勿食用、不宜食用或遵医嘱语义的原文必须登记为关键警示，不能删除 `warning` 标记绕过；
- 拦截没有直接对照的替代性比较、把无硫熏扩大为无残留风险、擅自限制使用方式和无来源的优惠叠加；
- P0 候选标记与决策池必须完全一致；普通版展示全部候选，包括暂缓候选，并说明未入选原因；
- 正式交付根目录拒绝修正脚本和可执行文件，普通版补充清理 `CLM-`、字段赋值和英文技术状态。

## 0.1.6 原文主张与关键字段防错修订

这是原文主张与关键字段防错修订版：

- 新增 `source_claim_ledger.jsonl`，在两遍页面身份核对后重新打开含文字来源，逐条摘录并复核可见原文；
- 营养表逐行、FAQ逐问、对比页逐侧登记，SKU、配料、营养、储存和警示作为关键主张，摘录后不得在事实层遗漏；
- 每条直接事实必须引用原文主张并保留逐字 `source_quotes`，事实中的数字和“好吸收、道地、适合某人群、遵医嘱、建议冷藏”等高风险词必须能回到原文；
- 增加文字密度与内容类型标记，拦截中高文字密度页面只有摘要、没有原文主张的伪完成；
- 普通版继续清理 `medium置信度` 等内部英文证据状态。

## 0.1.5 图片身份与双遍复核修订

这是图片来源身份绑定和双遍复核修订版：

- 新增 `build_source_audit_cards.py`：把来源编号、真实文件名、原文件 SHA-256 与原图像素固定在同一张 SVG 审计卡中，并由校验器复算卡片和内嵌原图哈希；
- 图片必须先按来源编号正序逐张初检，再按反向顺序逐张复核；两遍分别记录标题、摘录、序号和时间，阻止批量使用同一时间或沿用旧页面映射；
- 报告编号、日期、批次、证书编号和检测方法等精确值不能再从事实边界、FABE、缺口、限制或普通版绕过原件级核验；
- P0 不得由页面出现次数、覆盖页数或篇幅决定；没有用户原声或研究资料时，不得写很多、大多数或消费者普遍如何；
- 增加持续食用、整体加工安全、放心吃和全部法定强制项目等过度推导拦截，并净化普通版中的英文证据状态。

## 0.1.4 逐文件视觉核对修订

这是逐文件视觉核对、证据边界和客户版净化修订版：

- 新增 `source_observation.jsonl`，要求按真实路径逐个打开原文件后再建来源账本，阻止“文件名正确、页面语义仍错配”；
- 页面截图不再允许自证报告编号、日期、批次、证书编号或检测方法等小字精确字段；原件/PDF或官方验证页才可核验；
- 页面直接支持的 FABE 必须用与 Feature 直接相关的事实作为 Evidence，阻止无关检测页给其他体验价值背书；
- 增加安全底线、笼统健康、无添加、储存、气味、咀嚼和无竞品数据却写最强/唯一等越界拦截；
- P0 增加客户可读 `public_rationale`，普通版分开显示“当前使用限制”和“当前资料不能证明”，隐藏 blocked/deferred 价值及内部技术字段。

## 0.1.3 来源身份修订

这是来源可回溯和客户版净化修订版：

- 增加不可覆盖的 `source_inventory.jsonl`，以真实文件名、相对路径、大小和 SHA-256 固定来源身份；
- 本地来源必须绑定 `source_file_id`，阻止按阅读顺序虚构或重排图片编号；
- 为 `F-EVIDENCE` 增加细节置信度和精确字段复核门槛，报告编号、日期、批次等小字不可猜读；
- 阻止把“反复蒸晒”扩大为“九蒸九晒”、把“入口温和”扩大为“无刺激”，并限制价值范围不得超过事实覆盖的 SKU；
- 修复内部 ID 紧邻中文时的漏检，并清理普通版英文状态和表格多余 `>` 符号。

## 0.1.2 真实商品页质量修订

这是基于外部宿主真实商品页试跑的质量修订版：

- 增加 `sku_status` 和 `sku_basis`，禁止只凭标题片段锁定 SKU；
- 结构化交付 schema 升级至 0.1.1；
- 按交付更新时间核验动态活动的完整日期，阻止“活动中却写成已过期”等矛盾；
- 普通版隐藏内部资产 ID 时同步清理异常标点，并正确识别 P0—P3 缺口优先级；
- 增加食品与检测类表达边界，保留公开页面事实，同时阻止把检测报告扩大为安全认证、确保品质或特定健康人群适用结论。

## 0.1.1 元数据兼容性修订

这是 SkillHub 等宿主的元数据兼容性修订版：

- 将 `SKILL.md` 的 `description` 改为直接可提取的单行文本；
- 同步 Skill 运行版本和独立安装包；
- 商品事实、FABE、P0/P1/P2、证据边界、资料缺口及下游状态合同保持不变。

## 0.1.0 首发能力

- 从商品页、包装、手卡、参数、SKU、品牌资料和用户资料建立可回溯商品事实；
- 区分商品事实、第三方证据、品牌战略、动态权益、用户语言和分析推导；
- 建立 FABE、商品身份、识别锚、P0 候选、P0/P1/P2、资料缺口和表达边界；
- 输出普通用户可读文档和可供下游 Skill 读取的结构化交接数据；
- 不生成卖点画面、脚本、达人匹配或商业归因。
