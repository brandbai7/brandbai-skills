# 普通版导出格式

```text
BrandBAI_TikTok采集_对象_YYYYMMDD/
├─ 01_作品清单.xlsx
├─ 02_评论明细.xlsx          # 仅请求评论时
├─ 03_搜索快照.xlsx          # 仅搜索批量时
├─ 04_作品素材/
├─ 05_采集说明.md
└─ data/
   ├─ run_manifest.json
   ├─ works.jsonl
   ├─ comments.jsonl
   ├─ assets.jsonl
   ├─ input_selection.json
   ├─ profile_selection.json
   ├─ search_snapshots.jsonl
   └─ delivery_manifest.json
```

## 01_作品清单.xlsx

- `作品总览`：作品 ID、视频／图集、标题、发布文案、作者、发布时间、可见互动快照、置顶、选择原因、规范链接和完成状态。用户主动生成双语版时，另含识别语言、语言置信度、中文、English、翻译状态、翻译引擎和生成时间；原文列不被覆盖。
- `账号信息`、`主页选择`：仅主页批量生成，保留公开账号字段、位次和选择证据。
- `话题明细`：作品内页面可见话题和提及。
- `素材索引`：素材类型、顺序、文件、公开来源指纹、状态、字节数和失败原因。
- `完整性`：作品、素材、评论和选择范围分别写状态。
- `达人快照`：仅单作品生成；保存当前作品页已展示或加载的公开作者字段、快照时间和来源作品，不进入主页补齐，不下载头像。

## 条件工作簿

- `02_评论明细.xlsx`：评论 ID、作品 ID、层级、匿名作者标识、原文、时间、点赞、声明与保存回复数、采集时间。双语版追加识别语言、语言置信度、中文、English、翻译状态、翻译引擎和生成时间。
- `03_搜索快照.xlsx`：关键词、标签页、筛选、原始位次、作品类型、规范链接、采集时间和范围状态。
- `输入选择`：读取插件 Excel／selection JSON 时写入 `01_作品清单.xlsx`，保留选择顺序、作品 ID、来源页面、关键词、原始位次和规范链接。

## 空值规则

- 页面明确显示 0：写 `0`。
- 页面未展示：值留空，状态 `not_visible`。
- 用户未请求：状态 `not_requested`。
- 公开不可用：`not_available`。
- 公开页面没有提供用户请求的独立素材地址：`not_provided`；独立原声与对应 MP4 的成功状态分开记录。
- 采集异常：`failed` 并保留简短原因。
- K/M/B 页面缩写同时写入 `metric_text`；换算值写入独立解析列。

交付和 ZIP 不保存 Cookie、请求头、Chrome 资料夹、验证码、签名参数、短期访问令牌或完整带签名资源 URL。
