# 浏览器路线

## 支持页面

| 场景 | 规范路由 | 首版动作 |
| --- | --- | --- |
| 达人主页 | `https://www.tiktok.com/@handle` | 读取公开账号字段；冻结全部当前可见置顶和最近 N 条非置顶作品 |
| 单视频 | `https://www.tiktok.com/@handle/video/<id>` | 下载视频、封面、原声、发布文案、数据和可见一级评论 |
| 单图集 | `https://www.tiktok.com/@handle/photo/<id>` | 下载全部图集图片、封面、可用原声、发布文案、数据和可见一级评论 |
| 综合搜索 | `https://www.tiktok.com/search?q=<keyword>` | 冻结前 N 个当前可见结果及位次 |
| 视频搜索 | `https://www.tiktok.com/search/video?q=<keyword>` | 冻结前 N 个当前可见视频结果及位次 |
| 照片搜索 | `https://www.tiktok.com/search/photo?q=<keyword>` | 冻结前 N 个当前可见照片结果及位次 |
| 插件作品清单 | `作品清单.xlsx` 或 `brandbai.tiktok.selection/v1` JSON | 冻结文件内去重作品 ID 与顺序，再进入对应详情页补齐请求素材 |
| 标签／音乐页 | `/tag/<name>`、`/music/<name>-<id>` | 实验性：按可见列表快照处理，不承诺覆盖全部结果 |

## 页面识别要点

- TikTok 用 `@handle` 标识主页，不使用抖音 `sec_uid` 主页路由。
- `/video/` 与 `/photo/` 必须分开识别；图集的每张图片都有独立顺序。
- 详情页可能同时挂载相邻推荐作品，当前目标必须以地址栏作品 ID 为锚，不按 DOM 第一条内容猜测。
- 综合、视频、照片搜索是不同语境；搜索快照必须保存关键词、标签页、筛选、原始位次和采集时间。
- K/M/B 缩写必须同时保留页面原文；若换算为数字，应标记为解析值而非平台原始精确数。

## 正常交互

1. 使用可见 Chrome，先由用户完成登录、验证码和地区提示。
2. 观察公开页面和页面正常返回的数据；不读取登录凭据或浏览器存储。
3. 对主页／搜索先滚动发现，再冻结选择清单，之后才下载。
4. 对评论逐页或逐次滚动，记录终止证据、动作次数、声明数与实际保存数。
5. 页面出现验证、访问限制或结构变化时停止自动推进并保留部分状态。

插件选择文件只作为作品范围和页面可见快照，不能代替详情页素材核验。选择文件中的互动量单独保留为采集时点快照；详情页正常返回值优先，详情页未返回时保持未知，不把缺失字段自动补成 0。

## 资源域名边界

当次下载只接受 HTTPS 且主机属于 TikTok 可见资源域，包括 `tiktokcdn.com`、`tiktokcdn-us.com`、`tiktokv.com`、`tiktokv.us` 及其子域。不得把任意第三方 URL 当作可下载资源。带查询签名的 URL 只用于当次下载，交付索引保存去查询参数后的公开来源指纹或标记为 `transient_url_redacted`。
